# Reader 4 report: The Workflow Builder

Persona. An undergraduate who used Geneious in a course for one semester. Comfortable
with a graphical sequence viewer. Expects every operation to have a dialog. Has never
opened a terminal.

| Location | Issue | Suggested fix |
|---|---|---|
| What it is, "no menu item that generates one from a template" | Geneious ships workflow templates you copy and edit, so my first move would have been to look for one. The chapter only says none exists after I have already been told the window is where drawing happens. It never says what to do instead for a first chain. | Say in one sentence that there are no starter templates and that this chapter's five-step chain is the intended starting example. |
| What it is, "`lungfish-cli workflow builder-run` executes it" | A command in backticks in paragraph two, before I know I will never need it. I stopped to work out whether the window path required this. | Add "which you will not need if you work in the window" at first mention. |
| What it is, "The node-type model in the source does define eleven further types" | "In the source" means the program's code, which I have no way to look at. This reads as a note to a developer and I could not tell if it affected me. | Replace "in the source" with "inside a saved file". |
| Why you would do this, "which is why provenance exists" | Provenance is linked but not glossed here, and the chapter glosses read, adapter, FASTQ, paired-end, and bundle in place. I did not know whether it meant a log or a file. | Gloss it inline once, as the record of what was run on what. |
| Why you would do this, "A chain binds its input by a path relative to the project" | "Relative to the project" is used before the `@/` notation is shown in step 5. I had to read the paragraph twice, then again after step 5, to see they were the same idea. | Show `@/Imports/...` here at first mention rather than three sections later. |
| Before you start, "Download the folder `human-mito`" | The instruction gives a direct folder link and then says that link cannot be used, so I clicked it first and got a page I could not download from. The order defeated me. | Lead with the ZIP route and give the folder link only as the place to confirm the file names. |
| Before you start, "19,916 reads, which is 9,958 pairs, with a mean read length of 248.4" | I could not judge whether 19,916 reads is a lot or a little, or whether 248.4 bases is normal. It is presented as a fact to match, not a number to understand. | Say these figures exist so you can compare your own import, not so you can judge quality. |
| Before you start, "Turn on **Show Experimental Features** in **Settings > Advanced**" | Settings is not on the menu bar path I was given. In Geneious I would look under Preferences. The chapter does not say Settings opens from the app menu or with Cmd-comma. | Give the keystroke or the menu path that opens Settings. |
| Before you start, "not intended for production scientific work" | This warns me off using the feature, but the chapter then teaches me to use it for a whole procedure. I could not tell whether I was allowed to trust any result I produced. | Say plainly whether a result from this window is safe to report or is practice only. |
| Before you start, "Deacon also needs its human index, which the Plugin Manager lists under Databases" | This is the only install step in the chapter and it is a fragment at the end of a sentence, with no instruction to open the Plugin Manager, find the entry, or download it. My run would have failed at step 6. | Make it a numbered instruction with the menu path and a way to confirm the database is installed. |
| Procedure lead-in, "using fastp 1.3.6, Deacon 0.16.0, and seqkit 2.13.0" | I have no way to find out which versions my copy installed, and the chapter says counts will differ without saying how much difference is fine. | Say the version numbers are for the record and that any difference in counts is expected. |
| Step 1, "the node inspector is on the right" | Inspector is used as a known word. In Geneious the equivalent panel is called the options or document panel. I guessed from context. | Gloss it once as the panel showing the selected node's settings. |
| Step 1, "There is no **File > Save Workflow** item and no Cmd-S binding" | This is the single largest departure from what I expect, and it is delivered as a correction of an older manual rather than as a warning to me. I read it twice before believing it. | State it as a behaviour difference. Edits are saved when you click Run, and there is no manual save. |
| Step 1, "clicking **Run** saves the current drawing into the library before it starts" | So a chain I build but never run is never saved. The chapter does not say what happens to it if I close the window, and I would have lost work finding out. | Say what happens to an unrun drawing when the window closes. |
| Step 1, "It is a legacy path that asks you to pick a sample at run time" | Legacy is jargon here and the sentence tells me to ignore a box that is permanently on my canvas and cannot be deleted. I could not tell whether leaving it there would break my run. | Say that the unused anchor is harmless and can stay where it is. |
| Step 2, "the data type of each input and output port" | Data type is not glossed, though port is. The table then shows types like Reads (FASTQ Bundle) which I could not distinguish from the port name. | Gloss data type once and label the table columns to separate port name from type. |
| Step 2, "wiring single-end reads into it produces a step that finds no overlaps" | Single-end is used without gloss, though paired-end was glossed earlier. I had to infer it as the opposite. | Gloss single-end at this first use. |
| Step 2, "Those types are FASTQ Input, FASTA Input, BAM Input ... and Export" | Twelve names are listed for a paragraph that has already told me I can never place any of them. I read the whole list looking for something I needed to do and found nothing. | Cut the list or move it to an appendix, and keep only the sentence that the palette holds six. |
| Step 2, "a minimum length defaulting to 20 and a qualified quality defaulting to 15" | Qualified quality is not defined anywhere and appears only here. It is also inside the paragraph about nodes I cannot use, so I could not tell why I was being told. | Drop this detail or gloss the term. |
| Step 3, "press `Delete` or forward delete" | I do not know what forward delete is on a laptop keyboard with one Delete key. | Name the key combination, or say the Delete key alone is enough. |
| Step 3, "the cheap steps run first and the expensive human-read comparison sees fewer reads" | Cheap and expensive are used for cost in time, which I only worked out on the second read. In Geneious I would think of cost as money or credits. | Say faster and slower instead. |
| Step 4, "A node whose output fans out to two downstream nodes is legal in the editor ... and refused when you run it" | The editor lets me draw something that cannot run. That is the opposite of what a graphical tool taught me to expect, and I would only find out at Run. There is no way given to check before running. | Say there is no pre-run check for branching and that Run is where it is caught. |
| Step 4, "Two exceptions exist for node types outside the palette, where a reference output may feed an assembly input" | An exception explained for nodes I was told I cannot place. I read it twice trying to find out whether it applied to my chain. | Cut the exception or say it cannot arise in a chain you build here. |
| Step 4, "makes it play the system alert sound and drop the line" | A sound is the only feedback for a rejected connection. If my volume is muted I get no explanation at all. The chapter does not warn me. | Note that there is no on-screen message for a refused connection. |
| Step 5, "Every other node's numbers are already at the values this chapter uses" | I could not tell whether that means defaults or values I must set to match. Combined with step 5 documenting thirteen controls, I stopped to check. | Say the defaults are the chapter's values and no typing is needed. |
| Step 5, "The Settings section below documents all thirteen controls" | Thirteen controls but only ten are node parameters, and step 5 says nothing about where the other three live until the Settings section. I went looking in the inspector for them. | Say here that three of the thirteen are toolbar controls, not node settings. |
| Step 5, "opens the shared FASTQ/FASTA Operations dialog with an Apply button" | This is the dialog I expected for every operation, and it is mentioned once in a closing sentence with no procedure. I did not know if using it was an alternative route or a trap. | Say whether the Configure dialog and the inspector are interchangeable. |
| Step 6, "any node parameter it does not recognise or that is required and missing" | Six failure conditions in one sentence, and this last one I could not picture happening in a chain I built from the palette. | Split into a short list or say which of the six can occur in a hand-built chain. |
| Step 6, "A project opened read-only refuses the run" | I do not know how a project becomes read-only or how to tell that mine is. | Say what makes a project read-only and where that shows. |
| Settings, "**Quality threshold.** ... roughly a 3 in 100 chance that a base at the cutoff is wrong" | This is the only setting whose number is explained in plain terms, and I liked it, but it made the neighbouring entries feel unexplained by comparison. Window size says 5 is a compromise without saying between what units. | Give window size the same treatment, in bases. |
| Settings, "**Cut mode.** ... quality on an Illumina run usually falls off at the 3-prime end and that is the end right and tail trim from" | Four values, and the sentence explains two of them by saying they do the same thing, which left me unsure what the difference between right and tail is. | Say in one clause how right and tail differ, or that they behave the same here. |
| Settings, "**Maximum length.** ... over-long reads that point at joined-together fragments" | I did not know that two fragments could stick together during library prep, so the reason for the setting did not land. | Name the phenomenon in a short clause. |
| Settings, "Five options reach the command line" | The chapter told me the command-line section is optional, then places five command-line entries in the middle of the Settings section I do need. I read all five before realising none applied to me. | Move the five to the command-line section or mark them skippable. |
| Reading the results, "each run gets its own folder at `runs/<run-id>/` inside that bundle" | I have no instruction for opening a bundle to see inside it. In Geneious results appear as documents in a folder tree. I could not perform this step. | Say how to reach the run folder from the window, or that Finder's Show Package Contents is needed. |
| Reading the results, "Deacon removed 9,717 of 9,876 reads, leaving 159" | The chapter explains why this is correct, which I understood, but it does not tell me what to do next. I had built a chain that destroyed my data on purpose and the procedure never revises itself. | Say whether to rerun the chapter's chain without that node to see the alternative. |
| Reading the results, "The final bundle held 106 reads over 30,498 bases" | Starting at 19,916 and ending at 106 reads. I could not judge whether a chain that keeps half a percent of the input is a success or a warning. | Say plainly that this outcome is expected here and would be alarming elsewhere. |
| When a run fails, "A run made from the command line writes neither of those two files" | This matters only to command-line users but sits in the main results section, and it made me worry my window run was missing records. | Move it to the command-line section. |
| Comparing two versions, "Every saved chain carries a version such as `1.0.0`" | Nothing in the procedure ever showed me where to see or change a version, yet the diff example changes it from 1.0.0 to 1.1.0. I could not reproduce the example. | Say where the version is set, or that the window sets it automatically. |
| Comparing two versions, "a defect in 2026.9.13 makes all three print the text form" | A known bug stated without saying whether it will be fixed or whether I should avoid the feature. | Say the text output is still correct and only machine reading is affected. |
| What good looks like, "Open the `workflow.json` and confirm the input node's `bundle_path` begins `@/`" | This asks me to open a file inside a bundle in a text editor, which is the sort of step I was promised the window would replace. It is presented as a required check. | Say whether the window shows this, so the file check is a fallback rather than the method. |
| What good looks like, "The reference run's fused fastp call read `-q 15 -W 5 --cut_right`" | I am asked to compare command-line flags against inspector values, but nowhere am I told where in the window to find the command a run issued. | Say where the run's command line is displayed. |
| On the command line, "by typing commands into the Terminal application" | The section is marked optional, which I appreciated, but the two later checks in What good looks like depend on reading files and commands that only this section explains. | Make What good looks like fully performable from the window. |

Three closing lines.

The one thing I learned. A step can run without error and still be wrong for my
question, which is what the human-read removal did to human mitochondrial reads.

The one thing I still could not do. Install the Deacon human database, since the
chapter names it in half a sentence and never says to open the Plugin Manager.

The sentence I liked most. "A bundle with no parent recorded is a bundle whose history
stops at itself."
