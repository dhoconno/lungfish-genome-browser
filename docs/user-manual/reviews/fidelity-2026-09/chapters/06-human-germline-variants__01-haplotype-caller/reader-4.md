# Reader report: HaplotypeCaller

Reader 4. Undergraduate. I used Geneious in one class for a semester, mostly assembling Sanger reads and clicking through alignments. In Geneious every operation had a dialog with an OK button, and I never saw a command. I have never opened a terminal.

| Location | What stopped me | What would have helped |
|---|---|---|
| What it is, "runs GATK inside a managed software environment" | I do not know what a managed software environment is. In Geneious plugins just installed themselves and I never thought about where a tool lived. | Say it is a private folder LGE installs the tool into so it cannot clash with anything else. |
| What it is, "gives you the ten-subcommand GATK toolchain" | "Ten-subcommand toolchain" meant nothing to me. I do not know what a subcommand is. | Drop the count here, or say "nine other GATK commands". |
| What it is, "Turn on Show Experimental Features in Settings > Advanced" | This is the only place the whole chapter tells me to do this, and it is buried in a one-line paragraph in the middle of the overview, not in Before you start where I looked for setup steps. | Move this line into Before you start. |
| What it is, "This feature is experimental." | I do not know what experimental means for my results. Does it mean the numbers might be wrong, or just that the buttons might move? | One sentence saying whether the calls themselves are trustworthy. |
| What it is, "only the command line writes the GVCF" | This is the first time GVCF appears and it is not explained until Reading the results, several pages later. I was being asked to choose a route based on a word I did not know. | Gloss GVCF in half a sentence right here. |
| Why you would do this, "it holds 961 records over this window" | I could not tell whether 961 is a lot. The window is half a megabase and I have no feel for how many variants that should hold. | Say roughly how many variants a person carries per megabase. |
| Before you start, "click a filename and then the Download raw file button" | I followed this fine, but I do not know where the three files should go. Later steps say to import them, so does the folder matter? | Say any folder works, such as Downloads. |
| Before you start, "map them with Tools > Mapping > minimap2..." | The whole rest of the chapter depends on this, but it is one clause pointing at another chapter. I do not know how long the mapping takes or what it looks like when it is done. | Say roughly how long mapping this fixture takes. |
| Before you start, "A loose BAM in a folder cannot be called from in the window." | I read this three times. "Called from in the window" has two prepositions stacked and I could not parse it. In Geneious I could open any file and act on it, so this restriction is exactly the surprise that needs a clear sentence. | Say "The dialog cannot call a BAM file on its own, only a track inside a bundle." |
| Before you start, "reading SM:HG002 on this fixture" | I do not know what SM: is or where I would look to see it. | Say it is a tag in the BAM's header and that LGE sets it for me. |
| Before you start, "a first --execute run against a bare FASTA fails" | This whole sequence-dictionary paragraph is written for the command-line reader, but it sits in Before you start where I thought everything applied to me. I could not tell whether the dialog run needs the .dict file too. | Say plainly that dialog users do not need to make the .dict file. |
| Before you start, "the fix is the one command shown in the command-line section below" | I have never opened a terminal, so if this did apply to me I would be stuck with no path forward. | Say whether there is a way to do this without a terminal. |
| Before you start, "lungfish-cli conda install --pack gatk-core fails" | A whole paragraph about a command failing, addressed to someone at a terminal, placed before the Procedure I actually need. I skipped it and then worried I had missed a setup step. | Split the terminal-only half of this paragraph out of Before you start. |
| Procedure Step 2, "Step 0's Plugin Manager route is the fix" | There is no Step 0 in this chapter. The steps start at 1. I scrolled up looking for it. | Point at the Before you start paragraph by name. |
| Step 2, "The right side is a pane that scrolls." | This paragraph names six controls in one block and I lost track of which section each was in. A dialog description is exactly where I need a list or the screenshot. | Break the sections into a short list. |
| Step 2, "which fills itself in as the track name, a bullet, and the tool name" | I do not know what "a bullet" looks like in a field name. Is it a dot character? | Show the resulting name once, as an example. |
| Step 2, "Both fields are drawn for every caller in the list, and neither reaches GATK." | This is the sharpest surprise in the chapter for me. Geneious never showed me a field that did nothing. It took two readings to accept that the app deliberately shows a control that is ignored. | Say once, plainly, that these two fields are disabled in effect for GATK. |
| Step 2, "the two numbers are recorded with the run and then ignored" | If they are ignored, I do not understand why recording them helps me. | One clause on why they are recorded at all. |
| Step 3, "writes the VCF to variants/gatk/<track-id>.vcf.gz inside the bundle" | I do not know what a track id is or how I would find one. Angle brackets in a path are a convention I only half know. | Say the id is generated and I never need to type it. |
| Step 3, "loads the rows into a small SQLite database" | I do not know what SQLite is and this is the only mention. It made me think there was another file I had to manage. | Cut it, or say it is an internal index I never touch. |
| Step 3, "One default separates this run from its command-line twin" | I am not going to use the command line, so I could not tell whether this paragraph mattered to me. It ends by sending me to Step 4 of a section I will not read. | Say what the dialog user should do, without the comparison. |
| Step 4, "Sorting is by column header, and the Presets button" | I could not perform this. It does not say to click a header, and I do not know what a preset or a filter chip is. | Say "click a column header to sort". |
| Step 5, "the launcher finds nothing to run and falls through to the alert" | "Falls through" is programmer language. I understood the outcome but not this clause. | Say "so nothing happens and the alert appears". |
| Settings, "The default is the first analysis-ready BAM alignment track" | Analysis-ready is used four times across the chapter and never defined in one place. Step 1 gives "sorted and indexed" in passing, and I do not know what indexed means. | Gloss analysis-ready once, at first use. |
| Settings, "Minimum Allele Frequency ... The default is 0.05" | I am told what the number means and that it does nothing, so I could not judge whether 0.05 is sensible or arbitrary. | Say the default is inherited from other callers and has no effect here. |
| Settings, "or to change ploidy on a sample that is not diploid" | Ploidy is used before the --ploidy entry defines it, and Extra arguments is the only working route to it from the dialog, but no example of what to type is given. | Show one example string for the Extra arguments field. |
| Command-line only settings, whole section | Nine plus five entries of terminal flags sit between the Procedure and Reading the results, which is where I needed to go next. I scrolled past three screens of things I cannot use. | Move both command-line settings blocks after Reading the results. |
| `--stand-call-conf`, "The default is 30.0" | I cannot judge 30.0 against the QUAL numbers later, which run to thousands. I could not tell if 30 is nearly everything or nearly nothing. | Relate it to the QUAL figures in Reading the results. |
| `--threads`, "It does not work in this release." | I read this twice because the entry starts by documenting a setting and only then says the setting is broken. | Lead with the fact that it does not work. |
| Reading the results, "843 are SNVs ... and 184 are indels" | 843 plus 184 is 1,027, not the 1,026 stated. I checked twice and could not tell which number is wrong. | Fix the arithmetic or explain the one-row overlap. |
| Reading the results, "589 rows read 0/1 ... 418 read 1/1 ... 19 read 1/2" | The text then says "roughly three heterozygous for every two homozygous", but 589 to 418 is closer to seven to five, and What good looks like says heterozygous should be "near half". Three different framings of the same ratio. | Use one framing of the ratio. |
| Reading the results, "The mean QUAL across this fixture is 903" | I do not know what scale QUAL is on. "Higher is more confident" and "low tens is one to look at" gave me the two ends but nothing in between, so I cannot judge a call of 200. | Say what the scale is, or give a rough cut-off. |
| Reading the results, "38, against a mean of 44.7 across the whole aligned window" | I could not work out why the variant positions have lower depth than the window as a whole, and whether that gap is a problem. | One clause saying the difference is expected. |
| Reading the results, "the upright bar says WhatsHap worked out which copy" | WhatsHap is named seven times before this and never explained. I did not know it was a separate program until here. | Gloss WhatsHap at its first mention in Step 5. |
| Reading the results, "373 of the 589 heterozygous calls came back phased" | 188 plus 185 is 373, which checks, but 373 plus the 216 unphased is 589, so I could not see where the 19 `1/2` rows went. | Say whether `1/2` rows can be phased. |
| What good looks like, "A successful --execute prints two lines" | This whole check is terminal-only, but it sits in a section I read as the checklist for my dialog run. I do not know what the equivalent check is in the Operations panel. | Give the dialog equivalent of the exit check. |
| What good looks like, "Read the provenance record before you rely on a number." | I am told to read it but not where to find it in the window. The Operations panel screenshot caption mentions provenance, but no step says how to open it. | Say which click opens the provenance record. |
| On the command line, "This section is optional." | Only after the entire Settings section, two full pages of command-line flags, does the chapter tell me the command line is optional. | Say this at the top of the first command-line settings block too. |

One thing I learned. Reassembly is why HaplotypeCaller is slower and better around indels than a caller that reads one position at a time.

One thing I still could not do. Get from a downloaded FASTA and two FASTQ files to a finished run, because the mapping step is a single clause pointing at another chapter, and the sequence-dictionary and plugin-pack paragraphs left me unsure whether a terminal is required of me.

The sentence I liked most. "A simple caller walks the reference one position at a time and counts the bases stacked above it, so it judges every position on its own."
