## Consensus

Forty-two rows were hit by three or more readers.

- The `audience: power-user` label never says who the chapter is for.
- The preview note's print/`--execute` dry-run mechanic is unclear before any command has been shown.
- GATK is never expanded or glossed anywhere in the chapter.
- Phred quality scores are given two worked examples but no typical range to judge a real score by.
- The "several million" variant figure has no denominator against the genome's roughly three billion bases.
- The BAM fixture's download path is never given the same click-by-click GitHub instructions as the other two files.
- Three different disk-space numbers appear for what feels like one install, with no single figure to budget around.
- Exit status 3 is never explained or glossed.
- The first command block has no lead-in telling the reader to open a terminal or which folder to be in.
- A silent `samtools faidx` success gives no way to confirm the command actually worked.
- The elided `file:///.../` error path is never explained.
- Checksum is used with no gloss and is missing from the glossary list.
- Bundle is used with no gloss in the sequence-dictionary section.
- Bgzip is never explained as different from plain gzip.
- The chapter never states plainly that it does not actually need the real dbSNP download.
- Bcftools is used in commands without ever being introduced as installed, unlike samtools and GATK.
