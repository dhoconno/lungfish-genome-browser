The one thing I learned. The primer sequence physically becomes part of every copied molecule, so the first and last stretch of an amplicon read reports the primer rather than my sample, and a variant caller will happily call that primer a real mutation.

The one thing I still could not do. Open LGE and actually run a primer trim, or even find the Primer Scheme menu, because the Inspector and the workflow are named but never located on screen, and the only import instruction is a terminal command.

The sentence I liked most. "Those calls match no lineage, appear in no database, and track exactly with the protocol rather than with the biology."
