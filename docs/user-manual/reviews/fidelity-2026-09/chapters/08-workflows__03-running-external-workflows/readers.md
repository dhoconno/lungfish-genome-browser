# Merged reader report - Running External Workflows

Four readers reviewed this chapter. Personas were a genetics sophomore who has never opened a terminal, a wet-lab senior with two years of pipetting and no data analysis experience, a pre-med student reading in a second language, and an undergraduate who has used Geneious for one semester and expects a dialog for every operation. None had opened a terminal before.
