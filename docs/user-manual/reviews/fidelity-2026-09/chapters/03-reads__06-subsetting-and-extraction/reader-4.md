The one thing I learned. A subset bundle does not hold its own reads, it holds a note saying which parent and which operation, and LGE rebuilds the reads when something needs them.

The one thing I still could not do. Get my subset out as a plain FASTQ file to hand to someone else, because the only route given is a terminal command and I have never opened a terminal.

The sentence I liked most. "There are not forty thousand adapter-contaminated reads in this fixture."
