# Reader report: The Lungfish Genome Explorer Project

Reader 3. Pre-med student, English is my second language, genetics course
finished, never opened a terminal.

| Location | What stopped me | What would have helped |
|---|---|---|
| What it is, "A Lungfish Genome Explorer (LGE) project keeps..." | "Provenance" is used here with a link but no plain meaning in the sentence. I guessed it means where a thing came from, and I was not sure until much later in the chapter. | One short gloss at first use, like the chapter does for SQLite. |
| What it is, "Double-click it and the app..." | I did not know what "Show Package Contents" is. I have never used it. | Say it is a right-click menu item in Finder on a Mac. |

The one thing I learned. A project is one folder wearing the costume of a
single file, and the folder a file sits in is what tells me where that file
came from, `Imports/` from my own disk and `Downloads/` from the internet.

The one thing I still could not do. Build the demo project. The chapter
sends me to a GitHub page and never says whether that needs a terminal,
which I have never opened, so I could not follow the rest of the chapter
against the project it describes.

The sentence I liked most. "Whatever you select, the Inspector shows what is
known about it and what you can do next, and an empty Inspector means
nothing is selected."
