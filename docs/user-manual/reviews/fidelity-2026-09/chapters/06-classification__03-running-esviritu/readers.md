## Consensus

Seventeen rows were hit by three or more readers.

- Off-target PCR product is never glossed.
- The Segment table cell literally prints the words "em dash" instead of a value.
- No threshold is given for how thin a coverage window can be before it is a problem.
- RPKMF has no anchor or scale for what counts as high or ordinary.
- Readers cannot check how much memory their Mac has or whether 8 GB means total or free.
- The db-status terminal command is never marked as optional for window-only readers.
- The pairing fix never says what a correctly paired selection looks like.
- The toolVersion bug is never confirmed as affecting only the version label rather than the displayed numbers.
- The Inspector's three reference-validation states are unexplained and never say what action to take.
- The reference run table has no Unique Reads value, so the comparison the chapter itself asks for cannot be done.
- Curated viral assemblies is never glossed.
- The SRA download size and time are never given.
- The aside explaining trailing-colon punctuation on setting labels is confusing rather than helpful.
- The 170,180 read count has no pointer to where it is shown in the app.
- Small fraction, for the Unique Reads ratio, is never given as a number.
- Read packing is never glossed.
- The on-the-command-line section never states at its top that it is optional.
