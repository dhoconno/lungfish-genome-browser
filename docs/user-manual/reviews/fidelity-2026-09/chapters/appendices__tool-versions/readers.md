## Consensus

Twenty-seven rows were hit by three or more readers.

- Four program names, minimap2, GATK, and LoFreq among them, arrive in one sentence with no gloss for what any of them does.
- The Contents/Resources file path cannot be opened by a reader who does not know how to look inside a Mac app bundle, and nothing says they do not need to.
- The sentence naming the dependency set beside the app version is the one instruction readers need, but no example methods sentence is ever given.
- Readers are told to use the provenance sidecar instead of this page but are never told where a sidecar is or how to open one.
- "Four ideas separate the four tables" describes four columns, not four tables, and readers cannot line the claim up with what follows.
- The tilde in `~/.lungfish/conda` is never glossed as the home folder, and readers do not know the folder is hidden.
- The lock file jargon "key," "field," and "bootstrap" arrive unglossed in one already-long sentence.
- Odd version numbers such as `bedGraphToBigWig 482` leave readers unsure what to actually write in a citation, since no finished citation string is ever shown.
- The Plugin Manager instruction to open Tools > Plugin Manager stops short of what readers actually need, whether the next step, the cost, or whether any window shows versions at all.
- Repository, revision, and Nextflow arrive in one sentence with none glossed, even though Nextflow already appears as a tool in the first table.
- The forty-character commit identifier appears before the paragraph that explains it, reading as alarming rather than as a normal identifier.
- The four Source policy values appear in the table before any of them are explained, and one value is never explained anywhere.
- "The archive is trusted to keep its contents" reads to readers as either a reassurance or a warning, with no way to tell which.
- The exit status jargon in "What good looks like" means nothing to readers who have never opened a terminal or written a script.
- The PATH and shell explanation packs two unglossed terms and two alternative fixes into one dense sentence that readers cannot act on.
- The manual's own verification date reads as being about the writing process rather than about the reader, raising an unaddressed worry about staleness.
- The warning that a machine can hold an older installed version than the lock names arrives only on the chapter's last screen, after readers were already told to copy numbers from the tables.
- "Provisions on first use" is hard to parse, leaving readers unsure whether a tool is already installed or arrives later.
- The Executables column lists `python` for library rows, contradicting the earlier rule that the column names the program the environment provides.
- The `lungfish-cli conda install` command appears roughly 90 lines before the section explaining that the bare command name will not work.
- The `--revision <ref>` override uses an unexplained placeholder and never says who would actually need to override a pinned version.
- "The lock pins sixteen" gives a bare number with no noun, forcing readers to count the table rows themselves.
- The Kraken 2 database suffixes such as Standard-8 and PlusPF-16 are never explained, leaving readers unable to tell which database their own run used.
- The `lungfish-cli tools update --plan` command appears before the section explaining that the bare command name will not work, with no alternative offered for a mouse-only reader.
- The empty `retiredEnvironments` list gets a full paragraph that gives readers nothing to act on.
- The example showing "the bare name" appears right after being told the bare name will not work, reading as a trap.
- The provenance sidecar is named again in the closing section with still no location or link ever given for it.
