## Summary

The most common failure is a term used before it is defined, seen in RefSeqGene, mature protein, the join notation, fixture, and the dropped accession version, each hitting all four readers.
The second most common failure is a missing frame of reference for a number or state, readers cannot judge 102 features, a quality score, a checksum mismatch, or whether an import has finished without a stated scale or end state.
The one thing all four readers said they learned is that a position number means nothing without the name and version of the reference it was counted on.
