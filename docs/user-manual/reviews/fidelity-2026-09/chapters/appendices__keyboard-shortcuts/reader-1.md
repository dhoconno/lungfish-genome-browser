# Reader report, undergraduate reader 1

Persona: sophomore fresh from an introductory genetics course, no lab time, never opened a terminal, never used sequencing software.
Chapter: `docs/user-manual/chapters/appendices/keyboard-shortcuts.md`

| Location | Issue | Suggested fix |
| --- | --- | --- |
| What it is, "macOS calls the letter or symbol at the end of that combination the key equivalent" | "Key equivalent" is defined here and then never used again anywhere in the chapter. I read the sentence twice trying to work out what I was supposed to do with the term. | Drop the term, or use it in the table headings so the definition earns its place. |
| What it is, "Ctrl is the Control key at the far left of the bottom row" | On my laptop the far left of the bottom row is the fn key and Control is second. I looked at my keyboard, did not find it where the text said, and lost confidence in the rest. | Say Control is at the left end of the bottom row, near fn, without claiming it is the leftmost key. |
| What it is, "Every row below was read out of the source code that builds LGE's menus and views, not typed into the running app" | This tells me the shortcuts may not have been tested. As a student looking one up, that made me trust the tables less, which is the opposite of what a reference should do. | Say the rows come from the build so they match the app you installed, without the "not typed into the running app" clause. |
| What it is, "a tool inside the Tools menu's Genotyping submenu is dead until its software pack is installed" | "Software pack" is never explained, and I do not know how I would install one or find out whether one is installed. | One clause saying a software pack is an add-on set of analysis tools, with a pointer to the chapter that installs them. |
| What it is, "The Workflow Builder (Experimental)... item is stronger still" | "Stronger still" describes a menu item and I had to read it twice to see that it means the item is hidden rather than greyed. | Say the item is not greyed but hidden entirely. |
| How a shortcut is written here, "macOS treats the equals key and the plus key as the same physical key here" | I stared at my keyboard trying to find a separate plus key. On mine plus is Shift plus equals, so the sentence describes something I cannot see. | Say press the key that carries both equals and plus, and do not press Shift. |
| How a shortcut is written here, "Menu titles are quoted exactly as the app prints them, ellipsis included" | Nothing in the chapter is actually inside quotation marks, so I could not tell which text this rule applied to. | Say menu titles are written exactly as the app prints them. |
| Lungfish Genome Explorer menu, "Settings... Cmd-comma" | I do not know how to press "comma" as a shortcut. Every other row names a letter or a symbol and this one names a punctuation word. | Write it as Cmd-, with the character shown, or say press the comma key. |
| Lungfish Genome Explorer menu, "Check for Updates... is greyed out on a build that has no update feed configured" | "Update feed" and "build" are both new to me, and I have no way to tell which build I have. | One clause saying some copies of LGE update themselves and others are updated by hand. |
| File menu, "Import Center... Cmd-Shift-I" | I could not perform this from the text. Nothing says what the Import Center is or whether a project must be open first, and the File menu section never mentions a precondition. | One sentence saying the Import Center is the window for bringing files into a project, and that a project must be open. |
| File menu, "the Provenance submenu nested inside Export" | "Provenance" is used with no gloss. I guessed it means a record of where data came from but I was not sure. | Gloss provenance at first use as the record of how a result was produced. |
| View menu, "the Document Inspector is a separate window of manifest-level metadata for the bundle you have open" | Three unfamiliar words in one clause. "Manifest-level", "metadata", and "bundle" are all new, and I could not picture what this window shows. | Say it is a separate window listing what the open dataset is and where it came from. |
| View menu, "Restore Side Panes Cmd-Ctrl-Opt-F" | Four keys at once and no sentence anywhere says what this command restores or when I would need it. "Side panes" is also not the word used elsewhere, which is sidebar and Inspector. | One clause saying it brings the sidebar and Inspector back after Focus Viewer hid them. |
| View menu, "AI Assistant Cmd-Shift-A" | The AI Assistant appears in this table and again in the Help menu list with no explanation of what it does, so I did not know whether pressing it was safe. | One clause saying it opens a chat panel that answers questions about your data. |
| View menu, "Zoom Reset (10kb) Cmd-1" | I did not know what 10kb means as a view width, or why that is the reset value rather than the whole sequence. | Say it sets the view to a 10,000 base window, and that kb means kilobases. |
| View menu, "Larger is Cmd-Opt-plus" | The three Content Text Size shortcuts are given only in prose while every other group gets a table. Looking one up in a hurry, I scanned for a table and did not find them. | Put the three Content Text Size shortcuts in a table like the others. |
| View menu, "In a taxonomy viewport, meaning the tree of organism names a classifier produces" | "Classifier" is not explained. I could work out taxonomy from genetics class but not what software is doing the classifying. | Gloss classifier as software that decides which organism each read came from. |
| Sequence menu, "The two Extract and Copy commands take the region the viewport is showing" | "Viewport" is used from the start of the chapter and is only explained later, in the View menu section, as the display in the middle of the window. | Gloss viewport at its first use in the What it is section. |
| Sequence menu, "Go to Location... accepts a plain coordinate or a `chromosome:start-end` range" | I could not type this. Nothing shows an example of what an actual entry looks like, and I do not know whether to type the word chromosome or a name like chr11. | Give one worked example, such as chr11:5225464-5229395. |
| Sequence menu, "matches gene names from the annotation attached to whatever is open, which is the GFF or GenBank record the bundle carries" | GFF and bundle are both undefined here, and I had to read the clause twice to see that annotation and GFF are meant to be the same thing. | Say it matches gene names from the annotation file that came with the open sequence. |
| Sequence menu, "Copy Visible Region as FASTA Cmd-Shift-C" | FASTA is never glossed in this chapter even though it is in two rows and one paragraph. | Gloss FASTA at first use as the plain-text format that holds a sequence and its name. |
| Tools menu, "Plugin Manager... Cmd-Shift-B" | Earlier the chapter said software pack, here it says plugin. I could not tell whether these are the same thing. | Use one term for the add-on tools throughout the chapter. |
| Operations menu, "The Operations panel is the window that lists every pipeline LGE is running" | "Pipeline" is not explained, and I was not sure whether one pipeline means one analysis I started or something smaller. | Gloss pipeline as one analysis you started, running as a chain of steps. |
| Inside the sequence viewport, "Left and right pan the view by a hundred bases at a time" | I could not tell whether this is a hundred bases regardless of zoom, or a hundred pixels worth. At a 10kb view a hundred bases would barely move. | Say whether the step is fixed at a hundred bases or scales with the zoom level. |
| Inside the sequence viewport, "which is the way out of a very deep region that is taking a long time" | "Deep" is used in a sense I do not know. In genetics class depth was not a word about waiting. | Say a region covered by very many reads. |
| Inside the alignment viewport, "The compact read viewer that appears inside a classifier result window" | I could not press these shortcuts because I do not know how to get a classifier result window open, and the section never says. | Point to the chapter that produces a classifier result. |
| Inside the alignment viewport, "The shared code behind these accepts the equals key for plus and the underscore key for minus" | "The shared code behind these" is written for a programmer. As a student I do not care about the code, and the sentence made me stop. | Say the alignment viewport also accepts the equals and underscore keys. |
| Inside the genotype result window, "carries six shortcuts of its own" then a table of five | I counted the table twice because the number did not match. Escape is described after the table, so I could not tell whether it was the sixth or whether a row was missing. | Make the count match the table, or include Escape as a row. |
| Inside the genotype result window, "shows the alleles LGE called for each sample in a plate" | I know what an allele is, but "called" as a verb and "plate" are new in this sense. I could not picture what a plate is on screen. | Say a plate is one run of many samples analyzed together, and that called means the app's best guess at the allele. |
| Inside the genotype result window, "they work only when the window is on its Review lens or when a call is selected in a haplotyped MiSeq result" | "Review lens", "haplotyped", and "MiSeq" all in one clause, none explained. I could not tell whether my window qualifies, so I could not use any of the four shortcuts. | Split into two short sentences and gloss lens as one of the window's display modes. |
| Inside the genotype result window, "Cmd-Opt-P marks the selected cell a false positive, Cmd-Opt-N marks it a false negative" | I know these terms from statistics but not what marking a cell as one does to my data, or whether it can be undone. | One clause saying the mark is a note on the result and Cmd-Opt-R removes it. |
| Inside a classifier result window, "The TaxTriage result window" | TaxTriage appears with no gloss and is not in the Tools menu list above, so I could not tell what produces this window. | Gloss TaxTriage as one of LGE's classifiers at first use. |
| Inside a classifier result window, "Cmd-right bracket moves to the next sample" | Like Cmd-comma, this names a key by word rather than symbol, and I hunted for the bracket keys. | Show the characters, Cmd-] and Cmd-[. |
| Inside the sidebar, "These shortcuts belong to that context menu, so they work while it is open rather than as global bindings" | "Global bindings" is jargon. Also I do not understand how I press Cmd-Shift-N while a context menu is open without the menu closing. | Say the shortcuts work only while the right-click menu is showing. |
| Inside the Workflow Builder, "Its toolbar tooltips advertise Cmd-plus and Cmd-minus ... but no key binding matches those tooltips in this release" | A reference book telling me a documented shortcut does not exist made me wonder which other rows are wrong. It also sits in the middle of the chapter with no warning marker. | Move the known defect to a short note at the end of the section, marked as a known issue. |
| Memorizing chords, "knowing them is faster than memorizing forty-five separate rows" | I counted the tables and could not reach forty-five, so I stopped and recounted twice. | Drop the count or make it match the tables. |
| Memorizing chords, "A few patterns repeat" | The section is titled "chords" but the word chord is never defined, and it does not appear anywhere else until the Customizing section says "Press the new chord". | Gloss chord at first use as a combination of keys pressed together. |
| Customizing shortcuts, "Click the plus button, choose Lungfish Genome Explorer, and type the menu title" | I could not do this. The app in the list may be named "Lungfish Preview" rather than "Lungfish Genome Explorer", and nothing says what to do if the app is not listed. | Say the app appears under the name shown in its menu bar, and how to browse for it if it is missing. |
| Customizing shortcuts, "`Reverse Complement...` and `Translate...` both end in an ellipsis character" | An ellipsis character is one glyph, not three periods, and nothing tells me how to type it. Typing three periods would silently fail, which is exactly the failure the paragraph warns about. | Say to copy the title from the menu, or give the keystroke for the ellipsis character. |
| Accessibility, "Ctrl-Opt-M moves VoiceOver into the menu bar" | This is the only shortcut in the chapter that does nothing unless VoiceOver is already turned on, and the text does not say so or say how to turn it on. | Add that VoiceOver must be on first, and name its own on switch. |
| Accessibility, "Full Keyboard Access, under System Settings, Keyboard, "Keyboard Navigation"" | The label is given twice under two different names in one sentence, so I did not know which one to look for on screen. | Use the on-screen label once. |
| Whole chapter, no Prerequisites or Before you start section | Every other chapter I have read starts by telling me what must be open. Here roughly half the shortcuts need a specific window open first, and that condition is scattered through the prose instead of stated once. | Add one short section saying which shortcuts are global and which need a sequence, alignment, or result window open. |

One thing I learned: the Sidebar toggles with Control rather than Shift because that is the macOS standard, which explains an inconsistency I would otherwise have thought was a bug.

One thing I still could not do: press any of the genotype or classifier shortcuts, because the chapter never says how to get those windows open.

The sentence I liked most: "When a shortcut slips your mind, the menu bar prints it, and a context menu prints the ones that belong to it."
