# Reader report: Keyboard Shortcuts

Reader 4. Undergraduate. I used Geneious in one class for a semester, so I am comfortable in a graphical sequence viewer and I expect every operation to open a dialog. I have never opened a terminal. I read this appendix the way I would actually use it, which is looking one shortcut up in a hurry.

The one thing I learned is that LGE never asks me to save, because it writes every change to the project folder as it happens.

The one thing I still could not do is press the Help shortcut, because Cmd-? does not tell me which physical keys to hold on my keyboard.

The sentence I liked most is "When a shortcut slips your mind, the menu bar prints it, and a context menu prints the ones that belong to it."
