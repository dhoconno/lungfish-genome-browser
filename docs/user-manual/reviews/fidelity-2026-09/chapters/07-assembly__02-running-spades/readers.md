# Merged reader report, Running SPAdes

Four readers reviewed this chapter. Personas were a genetics sophomore who has never opened a terminal, a wet lab senior with two years of pipetting and no data analysis experience, a pre med student reading in a second language, and an undergraduate who has used Geneious. None had opened a terminal before.

## Consensus

Thirty-seven rows were hit by three or more readers.

- The k-mer tail and head overlap sentence needs the overlap shown on the existing example, since no reader could work out how many bases actually match.
- Every Settings entry ends with a command line sentence readers must learn to skip.
- Readers cannot find their own Mac's core count, so the Threads default is unpredictable.
- Readers cannot find their own installed memory, so the Memory Limit default is unpredictable.
- The Min Contig stepper is shown and editable but never reaches the SPAdes run.
- The pinned SKESA default of --min_count 2 is buried and unexplained.
- Run Mode's "which is the setting" phrasing reads as a typo across every reader.
- Coverage is used in Why you would do this before it is ever defined.
- "LGE sniffs the first FASTQ header" uses unglossed jargon for a basic action.
- The materialises and derived bundle sentence in the Procedure is the densest in the chapter.
- The "low thousands" read count threshold contradicts the fixture's own successful 9,958 pairs.
- The Inspector is never explained or shown to be reachable.
- The three named pane layouts are given with no description of what each one shows.
- The tidy bacterial isolate example omits its own genome size.
- Readers can read the coverage value out of a contig name but cannot judge if it is healthy.
- The GitHub folder download instruction is immediately contradicted and lacks a size estimate.
- The 110.7 second runtime figure cannot be scaled without knowing the reader's own core count.
- The stated count of eleven Settings controls does not match the actual number of bold entries.
- The Apple Silicon and --no-hw-accel behavior assumes a chip check readers cannot perform.
- The acceptable length margin against the published genome is never given as a number.
- Indel is used without a gloss anywhere in the chapter.
- Careful mode's own recommendation contradicts the instruction to leave every setting alone on the first run.
- The unclosed quote warning in Extra arguments uses parser and footer with no gloss.
- The mate suffix stripping sentence for Project Name never shows the resulting name.
- The imported bundle's row name is never given, so readers cannot confirm they clicked the right thing.
