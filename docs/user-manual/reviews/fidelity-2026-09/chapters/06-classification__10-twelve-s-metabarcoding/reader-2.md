# Reader report: 12S Amplicon Metabarcoding

Reader 2. A senior who has pipetted for two years, knows library prep and PCR, and has never analyzed data or opened a terminal.

| Location | What stopped me | What would have helped |
|---|---|---|
| What it is, "usually somewhere between 100 and 200 bases" | I know my amplicon length from the gel, but I could not tell whether this is a requirement my library has to meet or just background. If my amplicon is 250 bases, does the workflow break? | Say whether the length is a constraint or a description. |
| What it is, "A read that contains a reference sequence exactly" | Contains, not equals. I read this three times. My read is longer than the reference record and the reference has to sit inside it, which is the opposite of what I expected from the word match. | One clause saying the reference record is shorter than the read and must sit inside it. |
| What it is, "This differs from a classifier such as Kraken 2" | Kraken 2 arrives with no gloss and I have never used it. I could not tell whether it is a thing I have or a thing I would have to get. | One clause saying Kraken 2 is another workflow in LGE, or drop the name. |
| What it is, "So what should you do with this?" | The question is addressed to me but I have not run anything yet, so I did not know if I was supposed to act now or read on. | Cut the question or move the advice after the procedure. |
| Why you would do this, "none of the mapping or variant-calling workflows in this manual" | Mapping and variant calling are named as things I might have reached for, but I do not know what they are, so the contrast taught me nothing. | Point to the chapters instead of naming the methods. |
| Why you would do this, "the HG002 mitochondrial reads" | HG002 is used four times in the chapter and never explained. I guessed it is a sample name but not whose, or why a human sample is being run against primates. | One clause saying HG002 is a reference human sample. |
| Before you start, "Build the demo project first if you have not already" | This tells me to do something in another chapter with no pointer to it. I stopped here because I could not go on without the data. | A link to the demo-project instructions. |
| Before you start, "This is not the experimental-features switch" | It rules out a switch I did not know existed, which made me go looking in Settings for it anyway. | Delete the sentence or say where that switch is. |
| Before you start, "the plugin pack the workflow depends on, which the card names as `Lungfish Tools`" | Plugin pack is not explained here. I could not tell how big the install is, whether it needs the internet, or how long I would be waiting. | Say what Install Dependencies downloads and roughly how long it takes. |
| Before you start, "It expects reads that are already merged" | This is the most important sentence in the section and it is the last one, after I had already enabled the workflow. I do not know if my facility merged my reads or how I would check. | Move this up, and say how to tell whether a FASTQ is merged. |
| Before you start, "Merge them with a read-processing operation first" | A read-processing operation is named but not located. I do not know which menu it is under or what the operation is called. | Name the menu path or link the chapter. |
| Procedure step 1, "either as a plain FASTA or as a prepared `.lungfish12sref` bundle" | Two file types with unfamiliar extensions and no guidance on which I am likely to have. I did not know which branch of the instructions was mine. | Say which one a first-time user will have. |
| Procedure step 1, "open the dialog as described in step 2, then click Create 12S Reference..." | Step 1 sends me forward to step 2 and back again. I lost my place and had to reread both. | Renumber so the dialog opens first. |
| Procedure step 1, "a metadata table in the MIDORI style" | MIDORI is a proper noun I have never met, and MIDORI style is not defined beyond the four columns. I have no idea where such a file comes from. | Say what MIDORI is and where to get or build the file. |
| Procedure step 1, "for example `>Rhesus macaque (Macaca mulatta)`" | I could not tell whether this exact punctuation is required or just an example. If my FASTA headers are accession numbers, is the reference unusable? | Say whether the header format is required. |
| Procedure step 1, "LGE joins the two on the scientific name" | Joins is a data word I do not have. I guessed it means matching rows, but I could not tell what happens to a species present in one file and not the other. | Plain wording, and say what happens to an unmatched row. |
| Procedure step 2, "or pick one from the Project Reference menu above it if the workflow found candidates" | I could not tell how LGE decides something is a candidate, so I would not trust a menu entry I did not put there. | Say what makes a file a candidate. |
| Procedure step 2, "Selecting more than one bundle is allowed and they run together as one batch" | I could not tell whether the results stay separated by sample or get pooled into one roster. That changes whether I select all my samples at once. | Say that each sample keeps its own row. |
| Procedure step 2, "Give it a CSV or TSV of per-sample information" | I do not know what column names the file needs or how LGE knows which row belongs to which sample. I could not build this file from the text. | Name the required sample-identifier column. |
| Procedure step 3, "The remaining fields are covered one by one in Settings below, and their defaults are reasonable" | I was told to run before reading what half the dialog does. I did not know whether skipping ahead was safe or whether I would have to rerun. | Say explicitly that the defaults are fine for a first run and Settings can wait. |
| Procedure step 3, "resolves reads whose sequence is shared between species" | This is the first time a read can belong to two species, and the mechanism only arrives much later in Reading the results. I stopped to look for it. | Point forward to the explanation. |
| Procedure step 4, "% of Sample, Refs, and Alternates" | Nine column names in one sentence. Only three are explained in the paragraph that follows. I could not tell what Group or Tax ID are for. | Explain the columns as a short list rather than a sentence. |
| Procedure step 4, "A summary line above the table reports four figures separated by vertical bars" | Four figures with no labels, identified only by position. If I misremember the order I will misread the run. | Say what the figures look like on screen, or that they carry labels. |
| Procedure step 4, "then the percent of reads left unresolved" | Later, in Reading the results, the same figure is called the exact-match rate and given as 63.6 percent. I could not tell whether unresolved percent and exact-match percent are the same number or two different ones. | Use one name for the figure throughout. |
| Procedure step 5, "or that matched several species and could not be separated" | This contradicts the earlier statement that shared reads are resolved by abundance. I could not tell which reads end up here. | Say which ambiguous reads are resolved and which land in Unresolved. |
| Procedure step 5, "Sequence (the cluster's identifier)" | I could not tell whether this is a name I would recognise or a machine-generated string. It matters because the command line later asks me to name clusters with `--sequence-id`. | Show what a cluster identifier looks like. |
| Procedure step 6, "LGE sends the cluster sequence to BLAST, NCBI's public sequence search service" | My sequences leave my computer and go to a public server, and this is mentioned in passing. My lab has rules about that. | Flag that the sequence is sent off the machine. |
| Procedure step 6, "A high-identity hit to a plausible animal" | High identity is not a number. I know 99 percent is high and 70 percent is not, but I could not tell where the line sits for a 150-base fragment. | Give a percent identity to look for. |
| Procedure step 6, "takes noticeably longer than the local match" | Noticeably longer could be ten seconds or ten minutes, and I would not know whether to wait or assume it hung. | Give a rough time. |
| Procedure step 7, "Every export honours the filters described in Settings below" | I had not read Settings yet, so I did not know which filters were on. I could export a filtered table thinking it was the whole thing. | Say the filters are off by default. |
| Settings, "The dialog carries eight controls and the Inspector's 12S Results section carries six more" | Inspector appears here for the first time with no gloss and no way to open it. I never found it. | Say what the Inspector is and how to show it. |
| Settings, "Those closing sentences belong to the optional command-line section" | I was told to skip part of every entry, which made the whole section feel like it was written for somebody else. | Put the flags in a separate column or table. |
| Settings, Read Platform, "The default is Illumina exact, which accepts only reads that contain a reference sequence with no substitutions at all" | The picker in step 3 was called Illumina and here the setting is Illumina exact. I could not tell whether these are the same control. | Use the same label in both places. |
| Settings, Min Soft Clip, "how many of the read's own bases must sit on each side of the matched reference stretch" | Soft clip is a term from alignment that I have never met, and the glossary link is at the top of the file where I did not look. I read this entry three times and still could not picture it. | A one-line picture of the read overhanging the reference. |
| Settings, Min Soft Clip, "Raise it when short partial overlaps are producing matches you do not trust" | I have no way to tell from the results whether that is happening, and no sense of what raising it to means. 2? 20? | Give a value to try and a symptom to look for. |
| Settings, Max Indels, "so it is greyed out in the Illumina setting" | A default of 3 is stated for a field that is disabled by default. I could not tell whether 3 is ever in force. | Say the default only applies in ONT mode. |
| Settings, Run vsearch chimera review, "using vsearch" | vsearch is a tool name with no gloss in the text. I could not tell whether it is included or something I install. | One clause saying vsearch ships with the plugin pack. |
| Settings, Run vsearch chimera review, "a chimera looks exactly like a novel species until something checks it" | Chimera is linked but never explained in the prose. I know PCR artifacts from the bench but not that this specific word covers them. | Gloss chimera in the sentence as a PCR product spliced from two templates. |
| Settings, "The first three sit under the Target Rows disclosure and the last two under Unmatched Reads" | Three plus two is five, but six controls were promised and six are listed. I counted twice. | Fix the count. |
| Settings, Minimum Exact Reads, "the field accepts 0 to 1,000,000" | The range tells me nothing about what to type. I do not know whether a sensible cutoff is 5 or 500. | Suggest a starting value. |
| Settings, Taxon Groups, "each pill cycles through neutral, included, and excluded as you click it" | I could not work out the difference between neutral and included when everything is shown by default. | Say what neutral means when nothing else is set. |
| Reading the results, "173 merged reads went in, 110 matched exactly, and 63 were left unresolved, giving a 63.6 percent exact-match rate" | 173 reads is a tiny number compared with any run I have ever made. I could not tell whether the example is a toy or a realistic run. | Say the demo file is a small subset. |
| Reading the results, "the four other primates in the reference, the chimpanzee, the gorilla, and the two macaques" | Four other primates, then three names for four animals. I counted them twice before deciding two macaques is two. | Name all four. |
| Reading the results, "The default policy lets any nonzero lead win" | A single read of difference decides a species call, which sounds fragile, and I could not tell whether I can change the policy from the window. | Say whether the policy is changeable outside the command line. |
| Reading the results, "recorded in its own channel rather than folded silently into the exact-match counts" | Channel is not a word I have for data, and the text never says where I can see this record. | Say where the reassignments show up. |
| Reading the results, "56 unresolved clusters, all of them marked not detected, of which 51 held a single read, four held two reads, and one held four" | 51 plus 4 plus 1 is 56 clusters, but the reads add to 51 plus 8 plus 4, which is 63 and matches. I had to do the arithmetic to check the example was consistent. | State the read total so I do not have to. |
| What good looks like, "a well-matched reference against a clean amplicon library usually lands high" | High is the one number I most wanted and it is not given. The worked example at 63.6 percent is then called a trap, so I still cannot say whether my own result is good. | Give a rough percent range. |
| What good looks like, "The reads were oriented to match the reference before matching" | This is the first time orientation appears, in the section about judging results, and it turns out to be a required step before running. I had already run the workflow in my head without it. | Move orientation to Before you start. |
| What good looks like, "the reverse complement, meaning the same sequence read from the other strand" | The gloss is fine but nothing tells me how to know whether my own reads need orienting, and orienting is only available on the command line, which I do not use. | Say whether there is a way to orient reads in the window. |
| What good looks like, "A long thin table usually means the reference and the sample do not match each other well" | Long thin table is not a number. My result has forty rows and I could not judge it. | Give an approximate row count that should worry me. |
| What good looks like, "Click the information button at the right of the action bar" | The action bar has been mentioned three times but never located on screen. I do not know where to look. | Say where the action bar sits in the window. |
| On the command line, "they run headless, meaning with no window at all, by typing into the Terminal application" | I have never opened Terminal, and this section is the only route to a FASTA of unresolved clusters and the only route to orienting reads. Two things I need are behind a door I cannot open. | Say plainly that orienting and FASTA export require the command line. |
| On the command line, "The command's own help text lists only five of those seven" | A known bug is documented but there is no way for me to tell whether it has been fixed by the time I read this. | Give the version this applies to. |
| On the command line, "`--min-reads` defaults to 5" | Earlier the Inspector's Minimum Unresolved Reads defaults to 0 and here the export defaults to 5. Two defaults for what sounds like the same filter. | Say the two filters are separate. |

One thing I learned. Exact matching refuses to guess, so an unresolved cluster is information rather than a failure.

One thing I still could not do. Check whether my own reads are merged and correctly oriented, since both are required and neither has a route in the window.

The sentence I liked most. "A chimera looks exactly like a novel species until something checks it."
