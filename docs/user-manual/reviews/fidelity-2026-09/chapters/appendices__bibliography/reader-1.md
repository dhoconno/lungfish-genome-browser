One thing I learned. The provenance sidecar records the exact version and
command line of every tool that ran, so the citation list can be built from
the run itself rather than from memory.

One thing I still could not do. Open Terminal and get to my project folder,
because the `cd` and drag step never shows what I type or what I should see.

The sentence I liked most. "A citation says which tool you used and a
provenance sidecar says which build of it ran with which arguments, and a
methods section needs both."
