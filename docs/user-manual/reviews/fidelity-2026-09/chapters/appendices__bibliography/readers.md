## Consensus

Thirty rows were hit by three or more readers.

- The second command, `provenance export --format methods`, has no full worked example the way the first command does.
- The version-check command `lungfish-cli --version` is a late, terminal-only route to a number readers needed earlier.
- The version strings in the reference database table cannot be judged or reliably written into a methods section.
- The chapter never says where a pipeline states whether its component tools belong in a methods section, even though it then supplies the citations anyway.
- The instruction to cite the pipeline, the Nextflow paper, and the pipeline's own component tools sends the reader to documentation they cannot find.
- Readers are told to recheck whether an IQ-TREE 3 paper now exists but never told where to check.
- Secondary citation is never defined, so readers cannot tell whether both papers belong in the reference list.
- The claim that eight tools have never published a paper cannot be verified by counting the table's own rows.
- Readers are told to report two tools as defects with no place given to report them.
- Exit status and the exit codes 0 and 64 are never glossed, so readers cannot judge whether either number matters to them.
- The cross-reference to the workflow export chapter's matching pair has no link and cannot be checked.
- The claim that the command's output is four lines does not match what readers count in the example block.
- The paragraph on sidecar search order describes internal behavior with nothing the reader can act on.
- The example path `./Analyses/mapping-HG002` is never explained as something to replace with the reader's own folder.
- Readers cannot tell whether `lungfish-cli` works from any folder or what to do if it reports command not found.
- The four tool names in the opening definition of mapping, variant calling, and classification arrive with no gloss.
- The chapter's need for Terminal is disclosed only well into the section that requires it, not in the opening.
- The reviewer-wondering sentence buries its instruction to trim inaccurate citations behind the reason for it.
- Readers have no worked example of a finished citation in the style their own journal expects.
- The eight Kraken 2 database names in one table cell give no way to tell which one a reader's own run searched.
- The verb pin is used repeatedly before it is ever glossed.
- The Pack column's names, such as full-length-mhc-genotyping, are never explained.
- The key instruction to check which tools a provenance sidecar names has no shown way to open or read that sidecar.
- The phrase describing entries in LGE's own wording versus the manual's wording cannot be resolved by the reader.
- The DOI column shows bare strings with no `https://doi.org/` prefix even though the text says DOIs resolve there.
- The sentence describing which tools install without a plugin pack is ambiguous about whether they are already present.
- The list of twelve unglossed tool names gives readers no way to tell whether their own run used any of them.
- The partial-overlap matching rule is never explained well enough for readers to judge when it might mismatch.
- The steps for reaching a project folder by typing cd and dragging a folder are not exact enough to perform.
- The dependency set value 2026.2 is defined after it is named, and readers cannot find their own dependency set.
