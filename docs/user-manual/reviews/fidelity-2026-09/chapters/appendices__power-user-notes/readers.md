## Consensus

Fifty-three merged rows were hit by three or more readers.

- Nothing at the top of the chapter says which sections need a terminal, and the one section a window-only reader can act on, the Operations panel, arrives on page seven or eight.
- "Argument list" is never glossed, so readers do not know a tool is being run by typing words at it.
- The "Summarising cost" section never says whether the same totals appear anywhere in the app window.
- Source citations such as "ViralVariantCallingPipeline.swift:1229" never say whether a reader without a source checkout can skip that section.
- "Pure function" is an unglossed programming term in the Reading a command out of the source section.
- The mpileup table's -d 600000 read cap has no scale, since no typical amplicon depth is given.
- --extra-args is used before it is explained, many sections before its actual introduction.
- The codon-merging band of 0.40 to 0.60 is never explained biologically.
- LoFreq's description of alternate reads outnumbering the error rate is long, abstract, and uses an unglossed term.
- HG002 is named with no explanation of what it is.
- Dindel is named with no explanation and is not in the glossary.
- Seeing FATAL in a LoFreq version string alarms readers before the reassurance that the run is fine arrives after it.
- The sliding-window trim is named and given a value before it is ever explained.
- The @SQ SN header line and the BED file format are both used with no gloss.
- The backslash-t and ellipsis inside the -R '@RG\tID:...' example are never explained.
- The wording for which value wins, LGE's or the reader's, inverts between the minimap2 and BBMap sentences.
- Readers cannot tell whether an eight-column LGE kreport affects anyone who only uses the window.
- Readers cannot perform the .dict sequence dictionary fix, since the chapter only links elsewhere without naming the command.
- "Bundle" is used constantly across the chapter and is never glossed.
- The full JSON envelope block is never explained, so readers cannot tell which keys matter.
- A caller-default value is not flagged as meaning the reader's chosen setting had no effect.
- The two sidecar-count filenames are nearly identical and hard to tell apart in prose.
- Readers do not know zero normally means success, so an error line plus exit status 0 does not read as a contradiction.
- "Doubles" is never explained, so readers cannot picture what a doubled contig is.
- The explanation of the ignored --threads value on variants phase uses unglossed terms like root command and subcommand.
- Four exit codes for --plan are given in one paragraph with no table.
- --extra-args and the repeatable --extra-arg differ by one letter and are described only in prose.
- FORMAT DP and bcftools are unglossed, and the silent-match caveat is easy to miss.
- The opening sentence defining a plugin pack uses conda, environment, and transitive dependency with no gloss.
- The MEGAHIT reliability warning reads as contradictory and never gives the observed failure rate or a replacement assembler.
- "Flag" is used at its first appearance with no gloss.
- Readers cannot tell whether the mpileup section is meant to be typed or only read.
- Absolute path and scratch folder are both unexplained.
