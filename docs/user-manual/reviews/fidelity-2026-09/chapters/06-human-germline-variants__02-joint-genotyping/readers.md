## Consensus

Twenty-nine rows were hit by three or more readers.

- Terminal is never defined in the opening sentence, and the CLI Reference pointer arrives too late.
- The 0 and 1 in diploid-style genotype notation are never explained.
- Matched normal is never glossed.
- HG002 and slice are both used before either is defined.
- The tilde in the GATK install path is never explained.
- The 24-hour GATK step limit gives no sense of whether it is adjustable or what happens on timeout.
- Exit code 0 is never said to mean success.
- Step 3, reading the cohort VCF, cannot be performed from the text.
- The Dry run flag entry says it changes nothing before explaining its real override use.
- GQ, QUAL, and other thresholds sit on different scales that are never distinguished.
- The mean depth figure of 39.4 has no verdict attached.
- The GenomicsDB workspace files are never explained or marked as unnecessary to open.
- The header-line check in What good looks like cannot be performed on a compressed file.
- Experimental and the defect paragraph read as unclear or as developer notes rather than reader guidance.
- The three shared GATK flags are never named.
- The quality-score cutoff of 30 arrives before the Phred scale that would explain it.
- SHA-256 is never explained, only checksum.
- The download instructions never say how to get the GVCF or the `.fai` index, only the FASTA.
- The `--emit-ref-confidence GVCF` flag is quoted with no command shown around it.
- Pins is read as physically attaching something rather than as installing an exact version.
- The reads simply ran out is first read as reads escaping or a reagent running out, not as no coverage.
- The backslash line continuation character is never shown or named.
- Tabix is never glossed despite appearing several times.
- Passing a second copy of a flag through `--extra-args` is never shown with an example string.
- An unrecognised value silently falling back is never flagged as giving no later warning.
- The INFO-level DP and the sample-level DP conflict with no explanation of the difference.
- The three-dots path shortening in the sample output is not marked as specific to the book's own formatting.
- The confidence figure is never glossed as the same quantity later called GQ.
- The default-behaviour sentence for `--execute` explains the flag by naming it before saying it exists.
