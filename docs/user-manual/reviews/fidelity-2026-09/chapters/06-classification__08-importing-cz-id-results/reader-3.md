Three lines.

One thing I learned. CZ ID runs in a browser and LGE only reads its answer, so importing is about keeping the database versions with the numbers.

One thing I still could not do. Export the report from CZ ID. The chapter gives one sentence for the only step I must take outside LGE and names no button or page.

The sentence I liked most. "The record survives whatever happens to the account."
