One thing I learned. A plugin pack is a bundle of tools that LGE downloads on request, and it installs once for the whole machine rather than once per project.

One thing I still could not do. Run the offline install, because I have never opened a terminal and the chapter never says where those two commands are typed.

The sentence I liked most. "Run an operation that needs a tool you have not installed and it stops before doing any work, naming the tool and the pack."
