## Consensus

Twenty-six rows were hit by three or more readers.

- The shape metaphor for what these operations do is never cashed out in concrete terms.
- Mate is used before it is glossed.
- Depth of the whole dataset is never glossed at its first use.
- Pinning the tool version at 40.02 is never explained in plain terms.
- Library preparation and shears are lab terms used with no gloss.
- The read count of a bundle is never located on screen.
- K-mer Size defaulting to 50 is never glossed or justified before the reader must accept it.
- Importing a sequence as a reference is required but never explained or linked.
- The FASTQ viewport is named with no instructions for finding it.
- What the window shows when a K-mer value above 62 is rejected is never stated.
- Where the 70.283 percent merge report actually appears on screen is never named.
- Whether a standard deviation of 63.9 is tight or wide is never judged.
- The 91,148 read figure is never shown to be the read-pair count doubled.
- The correction counts (24,219 and 935 against 30,929 and 122,406) never reconcile.
- The switch to a nanopore mitochondrial dataset arrives with no warning.
- Over-fragmentation is named as a cause with no next action given.
- The coverage threshold behind "a few reads" is never given as a number.
- The command-line skip instruction conflicts with settings elsewhere that depend on the skipped section.
- The named tools, bbmerge, repair.sh, Tadpole, and vsearch, are never mapped to the operation each belongs to.
- File stem is never glossed at its first use.
- The advice on lowering Minimum Overlap reads as circular or backwards.
- Dust is never named as the masking algorithm behind Database Mask.
- The risk of a bad Extra argument, silent versus loud failure, is never stated.
- The frame header format, where it is visible, the code table term, and whether it is appended, is never explained together.
- The lower bound on true insert size is never given a size, so the reader cannot act on it.
- Reading inward from opposite ends of a fragment cannot be pictured from the text alone.
