# Reader report: Downloading from NCBI

Reader 3. Pre-med student, English is my second language, genetics course
finished, never opened a terminal.

| Location | What stopped me | What would have helped |
| --- | --- | --- |
| What it is / "A public sequence database holds finished..." | "Finished" as a word for a sequence. I know "finished" as done eating. Finished compared to what unfinished thing? | Say the sequence is complete and checked, not a work in progress. |
| What it is / "Each deposited sequence gets an accession..." | "Deposited". In my language this word is for money in a bank. I guessed it means submitted but I read it twice. | Use "submitted" the first time and "deposited" after. |
| What it is / "which opens a database search dialog on..." | "on its GenBank and Genomes pane". I did not know a dialog has panes, and I could not picture whether a pane is a tab or a side list. | One clause saying a pane is one page of the dialog picked from a list at the side. |
| What it is / "What lands is a reference bundle, a folder..." | "What lands". I thought something falls down. Also a folder with an extension confused me, because in my mind folders do not have extensions, files do. | Say the download produces a folder that macOS shows as one item. |
| What it is / "Annotations matter downstream because a variant caller..." | Two unknown things in one sentence. "Downstream" and "variant caller". I have never met either and neither is glossed here. | Gloss "variant caller" at first use, the way accession was glossed. |
| What it is / "SRA holds raw sequencing reads rather than..." | "Reads" used as a noun. In my genetics class a read was never a thing you can hold. | One short line saying a read is one stretch of sequence produced by the machine. |
| Why you would do this / "roughly two hundred thousand times smaller..." | I could not judge this. Two hundred thousand times smaller than something I do not have a number for. | Give the nuclear genome number too, so the ratio can be checked. |
| Why you would do this / "That record is the revised Cambridge Reference..." | I do not know what the revised Cambridge Reference Sequence is and it is never explained, only named. | Say in one clause that it is the agreed numbering standard for human mitochondrial DNA. |
| Why you would do this / "The GenBank version of the record carries 77..." | "13 protein-coding sequences, 22 transfer RNA genes". I know tRNA from class but "transfer RNA genes" written out took a second read to connect. | Write tRNA in brackets after the words, once. |
| Why you would do this / "That prefix is the reason this chapter can..." | I did not understand why a curated record means exact numbers can be promised. The link between curation and stability was not stated until the next sentence, so I read backwards. | Put the stability reason before the promise. |
| Before you start / "choose File > New Project (Cmd-N)" | The keyboard shortcut notation. I use a PC keyboard at home with a Windows key. I did not know which key is Cmd. | Name the key as the Command key once. |
| Before you start / "This chapter uses the human mitochondrial genome fixture..." | "Fixture". Unknown word in this sense. I only know a fixture as a lamp fixed to a wall. It is not in the glossary list at the top either. | Gloss "fixture" as the frozen test copy of the data. |
| Before you start / "Nothing in this chapter needs a plugin pack..." | Two product names I have never installed and cannot check. I did not know if I should worry about them. | Say plainly that these are extra installs some later chapters need but this one does not. |
| Procedure step 2 / "The Advanced Search Filters panel below the field..." | "stays collapsed until you click Show". I could not tell if Show is a button, a small arrow, or a word. | Name it as a button labelled Show. |
| Procedure step 3 / "Ticking more than fifty records asks you to confirm..." | The sentence has the ticking doing the asking. I read it three times to find who asks whom. | Say the app asks you to confirm when you tick more than fifty records. |
| Procedure step 4 / "reporting each stage in the Operations Panel." | The Operations Panel is named as if I know it. I did not see how to open it. | One clause saying where the Operations Panel is or how to show it. |
| Settings / "The second group, from Organism onwards, is the..." | There are two settings called Organism in this section, one for NCBI and one for Pathoplexus, both in the same bold form. I lost my place completely. | Label the second one Organism (Pathoplexus). |
| Settings, Mode / "Virus queries the NCBI Datasets virus service..." | "NCBI Datasets virus service" is a third name for a thing I do not know, next to Nucleotide and Genome which I half knew. | Say it is NCBI's separate virus collection. |
| Settings, RefSeq Only / "which is what you want when you are looking..." | The default is off and the reason given is a case I did not expect. As a student I would want the curated one, so the advice felt backwards and I stopped. | State the common student case, then the exception. |
| Settings, Include GFF3 / "cannot support amino-acid reporting later." | "Amino-acid reporting" is not defined anywhere I can see, and it is the whole reason to leave the box on. | Say it means being told which protein change a mutation causes. |
| Settings, Include GFF3 / "the nearest equivalent is --fasta-only on fetch genome" | I have never opened a terminal, so I could not tell whether this line was something I must do. | Mark command-line notes as skippable at the top of the Settings section, the way the last section does. |
| Settings, (search scope) / "(search scope)." | The setting has no real name, only a description in brackets. I could not find this control in my head, because I did not know what word to look for on screen. | Say it is the unlabelled popup beside the query field. |
| Settings, Sequence Properties / "among Has CDS, Has Gene, Has Source..." | "CDS" and "Has Source" are not explained. CDS I could guess from the earlier "protein-coding sequences" but only after going back. | Expand CDS once at this point. |
| Settings, Nucleotide Mutations / "written as reference base, position, and new base..." | I could not build one from this description. I did not know if it is A123T or A 123 T or something else. | One example string. |
| Settings, Amino Acid Mutations / "written as a gene name and a change separated..." | Same problem, and here I also did not know what a change looks like in a protein. | One example string. |
| Settings, INSDC Source / "Set it to Non-INSDC Only when you want records..." | I did not understand why anyone wants records they could not have found through NCBI. The purpose was missing. | Say these are submissions that exist only in Pathoplexus. |
| Reading the results / "Right-click it in the Finder and choose Show Package..." | The bundle is in the LGE sidebar in step 5 but here I must find it in the Finder. I did not know how to get from one to the other. | Say how to reveal the bundle in the Finder from the sidebar. |
| Reading the results / "It is a SQLite database, a single-file database engine..." | The gloss did not help me. "Database engine" is a new term used to explain a term. | Say it is one file holding a table of features. |
| Reading the results / "Nothing warns you when that happens." | This alarmed me and I did not know what to do about it. The next sentence explains what it means but never what action to take. | Say to re-run the download, or say the fallback track is still usable. |
| Reading the results / "the endpoint reads https://eutils.ncbi.nlm.nih.gov..." | A long list of field values I could not judge. I did not know which ones matter and which are just recorded. | Say which of these fields a reader should ever look at. |
| Reading the results / "wallTimeSeconds read 0.61 for that run" | Past tense "read" next to present tense "reads" in the same list. I thought it was a different word. | Keep one tense across the list. |
| What good looks like / "A number well below that usually means a partial..." | "Well below" is not a number. I do not know if 16,000 is well below 16,569. | Give a threshold, such as anything under 16,000. |
| When fetch genome returns a different accession / whole section | I do not use the command line and the heading names a command, so I skipped this section, then found the illustration about accessions was hidden inside it. | Put the accession illustration in the Why or Before you start section where a dialog user will see it. |
| When fetch genome returns / "a substituted reference gives every downstream..." | "Downstream coordinate" again, and I still do not know what downstream means in this manual. | Gloss downstream once, early. |
| Searching Pathoplexus / "holding ten outbreak-relevant pathogens" | I counted the list and got eleven names, because Sudan and Zaire ebolaviruses are written as one phrase. I could not tell if the count was wrong or my counting was. | Write the two ebolaviruses as two separate items. |
| Searching Pathoplexus / "they combine with AND logic across organism..." | "AND logic" is a programming idea. I guessed it means all filters must match but I was not sure. | Say all the filters you fill must match at once. |
| Searching Pathoplexus / "The nine filters described in the Settings section" | I counted the Pathoplexus settings by hand and was still unsure, because Organism is a chip row and not an item in that panel. | Say which nine, or drop the number. |
| Searching SRA / "with search, download, and info subcommands underneath it" | "Subcommands" and the whole paragraph are terminal things in a section that started by describing a menu item, so I did not know if the section still applied to me. | Split the menu part from the command-line part. |
| On the command line / the bash block with a trailing backslash | The backslash at the end of the first line. I did not know whether to type it or whether it is a page-break mark. | One line saying the backslash continues the command onto the next line. |

One thing I learned. An accession must be typed with its version number,
because curators revise records and the version is what pins the sequence
you actually get.

One thing I still could not do. Tell whether my downloaded annotation track
was the good one or the silent fallback, and what to do if it was the
fallback.

The sentence I liked most. "Curators revise deposited sequences and the
version number ticks up when they do, so a bare accession can quietly give
you a different sequence than a colleague got last year."
