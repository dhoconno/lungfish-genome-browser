One thing I learned: no reads over a stretch of genome looks exactly like no variants there, so the per-amplicon coverage table is the only thing that separates a failed amplicon from a region that genuinely matches the reference.

One thing I still could not do: judge my own run. Every threshold I would need, how long the run should take, how deep an amplicon must be, and how many N bases are too many, is given in words rather than numbers.

The sentence I liked most: "Nothing looks exactly like no change, which is the most dangerous way for an analysis to be wrong."
