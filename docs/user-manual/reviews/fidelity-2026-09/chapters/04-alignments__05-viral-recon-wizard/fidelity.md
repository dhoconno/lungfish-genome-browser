## Defects confirmed

1. `loadKnownParameters` fallback. `ViralReconWizardSheet.swift:551-566` returns
   `ViralReconRunRequest.overridableAdvancedKeys` when the pipeline schema JSON is

   `.unknownParameter`, whose message at `ViralReconWizardSheet.swift:545-546` is

   fallback's own comment says an empty set would refuse everything, so the
   fallback is deliberate, but the message is wrong for this case. Worth a fix.

   The Code Cartographer owns that file.
