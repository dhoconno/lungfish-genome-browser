One thing I learned. An ORF track is a list of candidates rather than a list of genes, and on a spliced gene like HBB it will find the wrong start and the wrong end for reasons that are normal rather than broken.

One thing I still could not do. Get exactly the 1,608 bases of the HBB gene using only the window, because the viewport frames a span that may be wider than what I typed and the chapter never tells me by how much or how to correct it.

The sentence I liked most. "An ORF track is a set of candidates, not a set of genes."
