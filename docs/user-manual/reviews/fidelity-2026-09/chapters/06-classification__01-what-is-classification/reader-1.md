One thing I learned. A classifier compares every read against a database and reports the most specific taxon it can defend, so the answer is a distribution across organisms rather than a single name for the whole sample.

One thing I still could not do. Select the right reads in the project sidebar and confirm the dialog picked them up, because the chapter never shows me what a correct selection looks like.

The sentence I liked most. "A hundred reads spread across a whole genome is a very different observation from a hundred reads stacked on one conserved gene, and only the first supports saying the virus is present."
