The one thing I learned. An alignment is a table in which each column is a
claim that those positions came from the same place in a shared ancestor,
and gaps exist only to keep the table rectangular.

The one thing I still could not do. Produce the pairwise identity matrix
inside the app. The chapter rests its whole verification argument on 0.926,
0.913, and 0.789, and the only route to them I could find is a terminal
command.

The sentence I liked most. "An alignment that says otherwise is telling you
something went wrong with the run, not something new about primates."
