==== build-db ====
OVERVIEW: Build SQLite databases from classifier results

USAGE: lungfish-cli build-db <subcommand>

OPTIONS:
  --version               Show the version.
  -h, --help              Show help information.

SUBCOMMANDS:
  taxtriage               Build SQLite database from TaxTriage results
  esviritu                Build SQLite database from EsViritu results
  kraken2                 Build SQLite database from Kraken2 results

  See 'lungfish-cli help build-db <subcommand>' for detailed help.

==== build-db taxtriage ====
OVERVIEW: Build SQLite database from TaxTriage results

USAGE: lungfish-cli build-db taxtriage <result-dir> [--force] [--no-cleanup] [--format <format>] [--verbose ...] [--quiet] [--progress] [--no-progress] [--debug] [--log-file <log-file>] [--no-color] [--threads <threads>]

ARGUMENTS:
  <result-dir>            Path to the TaxTriage result directory

OPTIONS:
  --force                 Force rebuild even if database exists
  --no-cleanup            Skip post-build cleanup of intermediate files
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.
