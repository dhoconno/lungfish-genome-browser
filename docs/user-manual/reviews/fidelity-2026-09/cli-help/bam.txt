==== bam ====
OVERVIEW: Operate on bundle-owned BAM alignment tracks

Use `lungfish-cli bam filter` to derive filtered alignment tracks and
`lungfish-cli bam annotate` to convert mapped reads into annotation tracks.
Use `lungfish-cli bam markdup` to mark duplicates in BAM workflows.

USAGE: lungfish-cli bam <subcommand>

OPTIONS:
  --version               Show the version.
  -h, --help              Show help information.

SUBCOMMANDS:
  filter                  Derive a filtered BAM alignment track from a bundle
                          or mapping analysis directory
  annotate                Convert mapped reads to annotations in a reference
                          bundle
  annotate-best           Create a new bundle with the best mapped read per
                          overlapping genomic interval
  annotate-cds-best       Create a new bundle with best CDS query gene and CDS
                          annotations
  markdup                 Mark PCR duplicates in BAM files using samtools
                          markdup
  primer-trim             Trim amplicon primers from a bundle BAM and adopt the
                          result as a new alignment track
  adopt-mapping           Attach a `lungfish map` result to a reference bundle
                          as a new alignment track

  See 'lungfish-cli help bam <subcommand>' for detailed help.

==== bam filter ====
OVERVIEW: Derive a filtered BAM alignment track from a bundle or mapping
analysis directory

USAGE: lungfish-cli bam filter [<options>] --alignment-track <alignment-track> --output-track-name <output-track-name>

OPTIONS:
  --bundle <bundle>       Path to the reference bundle directory
  --mapping-result <mapping-result>
                          Path to the mapping analysis directory
  --alignment-track <alignment-track>
                          Bundle alignment track identifier
  --output-track-name <output-track-name>
                          Display name for the derived alignment track
  --output-track-id <output-track-id>
                          Alignment track ID. Defaults to a generated portable
                          ID.
  --mapped-only           Exclude unmapped reads from the derived BAM
  --primary-only          Keep only primary alignments
  --min-mapq <min-mapq>   Minimum MAPQ score to retain
  --exclude-marked-duplicates
                          Exclude reads already marked as duplicates
  --remove-duplicates     Mark duplicates first, then exclude them from the
                          derived BAM
  --exact-match           Keep only exact matches (NM == 0)
  --min-percent-identity <min-percent-identity>
                          Minimum percent identity threshold
  --format <format>       Output format: text, json (default: text) (values:
                          text, json; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.

==== bam primer-trim ====
OVERVIEW: Trim amplicon primers from a bundle BAM and adopt the result as a new
alignment track

USAGE: lungfish-cli bam primer-trim [<options>] --bundle <bundle> --alignment-track <alignment-track> --scheme <scheme> --name <name>

OPTIONS:
  --bundle <bundle>       Path to the reference bundle directory (.lungfishref)
  --alignment-track <alignment-track>
                          Source alignment track identifier
  --scheme <scheme>       Path to the .lungfishprimers bundle directory
  --name <name>           Display name for the new primer-trimmed alignment
                          track
  --target-reference <target-reference>
                          Override the @SQ SN used to resolve the primer scheme
                          (defaults to the primer scheme's canonical accession)
  --ivar-min-quality <ivar-min-quality>
                          Minimum Phred quality for the sliding-window trim
                          (default: 20)
  --ivar-min-length <ivar-min-length>
                          Minimum read length to retain after trimming
                          (default: 30)
  --ivar-sliding-window <ivar-sliding-window>
                          Sliding-window width for ivar trim (default: 4)
  --ivar-primer-offset <ivar-primer-offset>
                          Primer coordinate offset (bp) (default: 0)
  --format <format>       Output format: text, json (default: text) (values:
                          text, json; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.
