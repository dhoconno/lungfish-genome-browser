==== gatk ====
OVERVIEW: Construct GATK4 commands for germline variant workflows

Builds reproducible GATK command lines by default. Pass --execute on a
subcommand to
run GATK through the managed gatk-core environment and write final-location
provenance.

USAGE: lungfish-cli gatk <subcommand>

OPTIONS:
  --version               Show the version.
  -h, --help              Show help information.

SUBCOMMANDS:
  haplotype-caller        Construct a GATK HaplotypeCaller command
  joint-genotype          Construct GATK joint genotyping commands
  filter                  Construct a GATK VariantFiltration command
  select                  Construct a GATK SelectVariants command
  variants-to-table       Construct a GATK VariantsToTable command
  bqsr                    Construct GATK BaseRecalibrator and ApplyBQSR commands
  markdup                 Construct a GATK Picard MarkDuplicates command
  validate-sam            Construct a GATK Picard ValidateSamFile command
  leftalign               Construct a GATK LeftAlignAndTrimVariants command
  collect-metrics         Construct a GATK Picard CollectVariantCallingMetrics
                          command

  See 'lungfish-cli help gatk <subcommand>' for detailed help.

==== gatk haplotype-caller ====
OVERVIEW: Construct a GATK HaplotypeCaller command

USAGE: lungfish-cli gatk haplotype-caller [<options>] --reference <reference> --bam <bam> --output <output>

OPTIONS:
  --execute               Run GATK and write final-location provenance.
  --dry-run               Print the GATK command preview without running it.
  --reference <reference> Reference FASTA path
  --bam <bam>             Input BAM path
  --output <output>       Output VCF or GVCF path
  --emit-ref-confidence <emit-ref-confidence>
                          Emit reference confidence: GVCF or NONE (default:
                          GVCF)
  --ploidy <ploidy>       Sample ploidy (default: 2)
  --intervals <intervals> Optional intervals BED/list/contig path
  --pcr-indel-model <pcr-indel-model>
                          GATK PCR indel model (default: CONSERVATIVE)
  --stand-call-conf <stand-call-conf>
                          Calling confidence threshold for non-GVCF mode
                          (default: 30.0)
  --max-alternate-alleles <max-alternate-alleles>
                          Maximum alternate alleles (default: 6)
  --pair-hmm-threads <pair-hmm-threads>
                          Native PairHMM threads (default: 4)
  --extra-args <extra-args>
                          Additional GATK arguments, written exactly as they
                          should be passed
  --version               Show the version.
  -h, --help              Show help information.

==== gatk bqsr ====
OVERVIEW: Construct GATK BaseRecalibrator and ApplyBQSR commands

USAGE: lungfish-cli gatk bqsr [--execute] [--dry-run] --reference <reference> --bam <bam> [--known-sites <known-sites> ...] --recal-table <recal-table> --output <output> [--intervals <intervals>] [--create-output-bam-index <create-output-bam-index>] [--extra-args <extra-args>]

OPTIONS:
  --execute               Run GATK and write final-location provenance.
  --dry-run               Print the GATK command preview without running it.
  --reference <reference> Reference FASTA path
  --bam <bam>             Input BAM path
  --known-sites <known-sites>
                          Known-sites VCF path. Repeat for dbSNP, Mills, or
                          cohort resources.
  --recal-table <recal-table>
                          Output recalibration table path
  --output <output>       Output recalibrated BAM path
  --intervals <intervals> Optional intervals BED/list/contig path
  --create-output-bam-index <create-output-bam-index>
                          Whether ApplyBQSR should create a BAM index (default:
                          true)
  --extra-args <extra-args>
                          Additional GATK arguments appended to both BQSR
                          commands
  --version               Show the version.
  -h, --help              Show help information.


==== gatk markdup ====
OVERVIEW: Construct a GATK Picard MarkDuplicates command

USAGE: lungfish-cli gatk markdup [--execute] [--dry-run] [--bam <bam> ...] --output <output> --metrics <metrics> [--create-index <create-index>] [--remove-duplicates] [--validation-stringency <validation-stringency>] [--extra-args <extra-args>]

OPTIONS:
  --execute               Run GATK and write final-location provenance.
  --dry-run               Print the GATK command preview without running it.
  --bam <bam>             Input BAM path. Repeat for multiple lanes.
  --output <output>       Output duplicate-marked BAM path
  --metrics <metrics>     Output duplicate metrics path
  --create-index <create-index>
                          Whether MarkDuplicates should create a BAM index
                          (default: true)
  --remove-duplicates     Remove duplicates instead of only marking them
  --validation-stringency <validation-stringency>
                          Picard validation stringency, such as STRICT,
                          LENIENT, or SILENT
  --extra-args <extra-args>
                          Additional GATK/Picard arguments, written exactly as
                          they should be passed
  --version               Show the version.
  -h, --help              Show help information.
