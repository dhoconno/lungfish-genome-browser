==== cz-id ====
OVERVIEW: Import and view CZ-ID classification results

Import CZ-ID hosted metagenomics taxon report TSV exports into Lungfish's
classification result schema. This command imports existing CZ-ID outputs;
it does not run or submit data to CZ-ID.

USAGE: lungfish-cli cz-id <subcommand>

OPTIONS:
  --version               Show the version.
  -h, --help              Show help information.

SUBCOMMANDS:
  import                  Import a CZ-ID taxon report TSV into a Lungfish
                          result directory
  summary (default)       Display a summary of a CZ-ID taxon report TSV

  See 'lungfish-cli help cz-id <subcommand>' for detailed help.

==== cz-id import ====
OVERVIEW: Import a CZ-ID taxon report TSV into a Lungfish result directory

USAGE: lungfish-cli cz-id import [--format <format>] [--verbose ...] [--quiet] [--progress] [--no-progress] [--debug] [--log-file <log-file>] [--no-color] [--threads <threads>] <input-path> [--output-dir <output-dir>]

ARGUMENTS:
  <input-path>            Path to a CZ-ID taxon report TSV, ZIP archive, or
                          extracted export folder

OPTIONS:
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  -o, --output-dir <output-dir>
                          Output directory for the imported result (default:
                          ./cz-id-{sample})
  --version               Show the version.
  -h, --help              Show help information.


==== cz-id summary ====
OVERVIEW: Display a summary of a CZ-ID taxon report TSV

USAGE: lungfish-cli cz-id summary [--format <format>] [--verbose ...] [--quiet] [--progress] [--no-progress] [--debug] [--log-file <log-file>] [--no-color] [--threads <threads>] <input-path> [--top <top>]

ARGUMENTS:
  <input-path>            Path to a CZ-ID taxon report TSV

OPTIONS:
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --top <top>             Number of top taxa to display (default: 20) (default:
                          20)
  --version               Show the version.
  -h, --help              Show help information.
