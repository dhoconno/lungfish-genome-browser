==== fetch ====
OVERVIEW: Fetch sequences from remote databases

USAGE: lungfish-cli fetch <subcommand>

OPTIONS:
  --version               Show the version.
  -h, --help              Show help information.

SUBCOMMANDS:
  ncbi (default)          Fetch sequence from NCBI by accession
  search                  Search NCBI databases
  sra                     Search and download from SRA (Sequence Read Archive)
  ena                     Search and download from ENA (European Nucleotide
                          Archive)
  genome                  Download genomes from NCBI and create indexed bundles

  See 'lungfish-cli help fetch <subcommand>' for detailed help.

==== fetch ncbi ====
OVERVIEW: Fetch sequence from NCBI by accession

Download sequences from NCBI GenBank/RefSeq databases.

Examples:
  lungfish fetch ncbi NC_002549 --save-to ebola.gb
  lungfish fetch ncbi NC_002549 --fetch-format fasta --save-to ebola.fa
  lungfish fetch ncbi MN908947.3 --fetch-format gff3 --save-to MN908947.3.gff3
  lungfish fetch ncbi MN908947 NM_000546 --save-to sequences.gb

USAGE: lungfish-cli fetch ncbi [<options>] <accessions> ...

ARGUMENTS:
  <accessions>            Accession number(s)

OPTIONS:
  --db <db>               Database: nucleotide, protein (default: nucleotide)
                          (default: nucleotide)
  --fetch-format <fetch-format>
                          Fetch format: genbank, fasta, gff3, xml (default:
                          genbank) (default: genbank)
  --save-to <save-to>     Output file path
  --api-key <api-key>     NCBI API key for higher rate limits
  --no-retry              Do not retry HTTP 429 rate-limit responses
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.

==== fetch sra ====
OVERVIEW: Search and download from SRA (Sequence Read Archive)

Search for sequencing reads in the NCBI Sequence Read Archive and
download FASTQ files. Downloads use ENA mirrors for direct HTTP access
(no SRA Toolkit required).

Examples:
  lungfish fetch sra search "SARS-CoV-2 Illumina" --limit 10
  lungfish fetch sra download SRR11140748 --output-dir ./fastq
  lungfish fetch sra info SRR11140748

USAGE: lungfish-cli fetch sra <subcommand>

OPTIONS:
  --version               Show the version.
  -h, --help              Show help information.

SUBCOMMANDS:
  search (default)        Search SRA for sequencing runs
  download                Download FASTQ files from SRA
  info                    Get information about an SRA run

  See 'lungfish-cli help fetch sra <subcommand>' for detailed help.

==== fetch genome ====
OVERVIEW: Download genomes from NCBI and create indexed bundles

Downloads a genome from NCBI, including the FASTA sequence and GFF3
annotations, then creates a .lungfishref bundle with proper indices.

Assembly accessions (GCF_/GCA_) are resolved through the assembly
database. Any other accession is fetched from nucleotide, which
returns the exact record requested: asking the assembly database for
a nucleotide accession returns the linked assembly instead, under a
different sequence name.

The bundle contains:
- Compressed, indexed FASTA (bgzip + samtools faidx)
- SQLite annotation database (converted from GFF3)
- Manifest with metadata

Examples:
  lungfish fetch genome GCF_003047895.1 --output-dir ./genomes
  lungfish fetch genome MN908947.3 --output-dir ./genomes
  lungfish fetch genome GCF_000001405.40 --name "Human GRCh38" --output-dir ./
  lungfish fetch genome GCF_003047895.1 --fasta-only --output-dir ./

USAGE: lungfish-cli fetch genome [<options>] <accession>

ARGUMENTS:
  <accession>             Assembly (GCF_003047895.1) or nucleotide (MN908947.3)
                          accession

OPTIONS:
  --output-dir <output-dir>
                          Output directory for the bundle (default: current
                          directory) (default: .)
  --name <name>           Bundle name (default: derived from assembly)
  --fasta-only            Download only the FASTA sequence (no annotations, no
                          bundle)
  --no-bundle             Download files but don't create a .lungfishref bundle
  --api-key <api-key>     NCBI API key for higher rate limits
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.
