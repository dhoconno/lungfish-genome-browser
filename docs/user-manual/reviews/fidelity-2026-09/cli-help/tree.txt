==== tree ====
OVERVIEW: Infer and transform phylogenetic tree bundles

USAGE: lungfish-cli tree <subcommand>

OPTIONS:
  --version               Show the version.
  -h, --help              Show help information.

SUBCOMMANDS:
  infer                   Infer phylogenetic trees from native alignment bundles
  export                  Export tree bundle payloads with provenance
  reroot                  Re-root a .lungfishtree bundle and write a new bundle
                          with provenance
  extract-subtree         Extract a selected clade as a new .lungfishtree
                          bundle with provenance
  relabel                 Relabel tree tips from bundle metadata.tsv and write
                          a new bundle with provenance

  See 'lungfish-cli help tree <subcommand>' for detailed help.

==== tree infer ====
OVERVIEW: Infer phylogenetic trees from native alignment bundles

USAGE: lungfish-cli tree infer <subcommand>

OPTIONS:
  --version               Show the version.
  -h, --help              Show help information.

SUBCOMMANDS:
  iqtree (default)        Infer a maximum-likelihood tree from a .lungfishmsa
                          bundle using IQ-TREE

  See 'lungfish-cli help tree infer <subcommand>' for detailed help.

==== tree infer iqtree ====
OVERVIEW: Infer a maximum-likelihood tree from a .lungfishmsa bundle using
IQ-TREE

USAGE: lungfish-cli tree infer iqtree [<options>] <msa-bundle-path> --project <project> --output <output>

ARGUMENTS:
  <msa-bundle-path>       Input .lungfishmsa bundle

OPTIONS:
  --project <project>     Lungfish project directory for project-local staging
  --output <output>       Output .lungfishtree bundle path
  --rows <rows>           Optional comma-separated row IDs or display names
  --columns <columns>     Optional 1-based aligned column ranges, e.g. 10-40,55
  --name <name>           Output tree bundle name
  --model <model>         IQ-TREE model string (default: MFP)
  --sequence-type <sequence-type>
                          IQ-TREE sequence type: auto, DNA, AA, CODON, BIN,
                          MORPH, NT2AA (default: auto)
  --bootstrap <bootstrap> Ultrafast bootstrap replicate count
  --alrt <alrt>           SH-aLRT replicate count
  --seed <seed>           Random seed (default: 1)
  --safe                  Enable IQ-TREE safe numerical mode
  --keep-identical        Keep identical sequences in the IQ-TREE analysis
  --extra-iqtree-options <extra-iqtree-options>
                          Additional IQ-TREE options, written exactly as they
                          should be passed to IQ-TREE
  --extra-args <extra-args>
                          Additional IQ-TREE arguments passed verbatim
  --iqtree-path <iqtree-path>
                          Override path to iqtree3 executable
  --force                 Overwrite an existing output bundle
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.

==== tree export subtree ====
