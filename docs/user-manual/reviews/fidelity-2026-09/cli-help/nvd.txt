==== nvd ====
OVERVIEW: Import and view NVD classification results

Import results from the Novel Virus Diagnostics (NVD) Snakemake pipeline.
Parses *_blast_concatenated.csv(.gz) files containing BLAST hit rankings and
per-contig mapped read counts for wastewater viral surveillance.

USAGE: lungfish-cli nvd <subcommand>

OPTIONS:
  --version               Show the version.
  -h, --help              Show help information.

SUBCOMMANDS:
  import                  Import NVD results into a Lungfish project
  summary (default)       Display summary of NVD results

  See 'lungfish-cli help nvd <subcommand>' for detailed help.

==== nvd import ====
OVERVIEW: Import NVD results into a Lungfish project

USAGE: lungfish-cli nvd import [--format <format>] [--verbose ...] [--quiet] [--progress] [--no-progress] [--debug] [--log-file <log-file>] [--no-color] [--threads <threads>] <input-path> [--output-dir <output-dir>] [--name <name>]

ARGUMENTS:
  <input-path>            Path to NVD results directory (containing
                          05_labkey_bundling/)

OPTIONS:
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  -o, --output-dir <output-dir>
                          Output directory for the imported bundle (default:
                          current directory)
  --name <name>           Override the bundle name (default: nvd-{experiment})
  --version               Show the version.
  -h, --help              Show help information.


==== nvd summary ====
OVERVIEW: Display summary of NVD results

USAGE: lungfish-cli nvd summary [--format <format>] [--verbose ...] [--quiet] [--progress] [--no-progress] [--debug] [--log-file <log-file>] [--no-color] [--threads <threads>] <input-path> [--top <top>]

ARGUMENTS:
  <input-path>            Path to NVD results directory or
                          *_blast_concatenated.csv(.gz) file

OPTIONS:
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --top <top>             Number of top contigs to display (default: 20)
                          (default: 20)
  --version               Show the version.
  -h, --help              Show help information.
