==== metadata ====
OVERVIEW: Manage FASTQ sample metadata

View, edit, import, and export PHA4GE-aligned metadata for FASTQ
dataset bundles (.lungfishfastq) and folders containing them.

Per-bundle metadata is stored in `metadata.csv` inside each bundle.
Folder-level metadata is stored in `samples.csv` at the folder root.

Examples:
  lungfish metadata get SampleA.lungfishfastq
  lungfish metadata set SampleA.lungfishfastq --field sample_type --value
"Nasopharyngeal swab"
  lungfish metadata import ./RunFolder samples.csv
  lungfish metadata export ./RunFolder

USAGE: lungfish-cli metadata <subcommand>

OPTIONS:
  --version               Show the version.
  -h, --help              Show help information.

SUBCOMMANDS:
  get (default)           Display metadata for a FASTQ bundle
  set                     Set a metadata field on a FASTQ bundle
  import                  Import folder-level metadata from a CSV file
  export                  Export folder metadata as CSV to stdout
  export-biosample        Export folder metadata as NCBI BioSample submission
                          TSV

  See 'lungfish-cli help metadata <subcommand>' for detailed help.

==== metadata get ====
OVERVIEW: Display metadata for a FASTQ bundle

Shows all metadata fields for a .lungfishfastq bundle, read from
the bundle's metadata.csv file.

Examples:
  lungfish metadata get SampleA.lungfishfastq
  lungfish metadata get SampleA.lungfishfastq --format json

USAGE: lungfish-cli metadata get <bundle-path> [--format <format>] [--verbose ...] [--quiet] [--progress] [--no-progress] [--debug] [--log-file <log-file>] [--no-color] [--threads <threads>]

ARGUMENTS:
  <bundle-path>           Path to the .lungfishfastq bundle

OPTIONS:
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.


==== metadata set ====
OVERVIEW: Set a metadata field on a FASTQ bundle

Sets or updates a single metadata field in a .lungfishfastq bundle's
metadata.csv file. Creates the file if it doesn't exist.

Field names use PHA4GE/NCBI BioSample conventions (snake_case).
Common fields: sample_name, sample_type, collection_date, geo_loc_name,
host, sample_role, patient_id, run_id, batch_id.

Examples:
  lungfish metadata set Sample.lungfishfastq --field sample_type --value
"Blood"
  lungfish metadata set Sample.lungfishfastq --field sample_role --value
negative_control
  lungfish metadata set Sample.lungfishfastq --field custom_notes --value
"Re-extracted"

USAGE: lungfish-cli metadata set <bundle-path> --field <field> --value <value> [--format <format>] [--verbose ...] [--quiet] [--progress] [--no-progress] [--debug] [--log-file <log-file>] [--no-color] [--threads <threads>]

ARGUMENTS:
  <bundle-path>           Path to the .lungfishfastq bundle

OPTIONS:
  --field <field>         Metadata field name (e.g., sample_type,
                          collection_date)
  --value <value>         Value to set for the field
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.


==== metadata import ====
OVERVIEW: Import folder-level metadata from a CSV file

Reads a CSV file and writes it as samples.csv into the specified folder.
Also syncs metadata to per-bundle metadata.csv files for bundles whose
sample_name matches a bundle directory name.

The CSV must have a header row. The `sample_name` column is used to
match rows to .lungfishfastq bundles in the folder.

Examples:
  lungfish metadata import ./RunFolder samplesheet.csv
  lungfish metadata import ./RunFolder samplesheet.csv --sync-bundles

USAGE: lungfish-cli metadata import <folder-path> <csv-path> [--sync-bundles] [--format <format>] [--verbose ...] [--quiet] [--progress] [--no-progress] [--debug] [--log-file <log-file>] [--no-color] [--threads <threads>]

ARGUMENTS:
  <folder-path>           Path to the folder containing .lungfishfastq bundles
  <csv-path>              Path to the CSV file to import

OPTIONS:
  --sync-bundles          Also write per-bundle metadata.csv files
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.


==== metadata export ====
OVERVIEW: Export folder metadata as CSV to stdout

Reads metadata from all .lungfishfastq bundles in a folder and outputs
a combined CSV to stdout. Uses resolved metadata (per-bundle metadata.csv
takes precedence over folder-level samples.csv).

Examples:
  lungfish metadata export ./RunFolder
  lungfish metadata export ./RunFolder > samples.csv
  lungfish metadata export ./RunFolder --format tsv

USAGE: lungfish-cli metadata export <folder-path> [--format <format>] [--verbose ...] [--quiet] [--progress] [--no-progress] [--debug] [--log-file <log-file>] [--no-color] [--threads <threads>]

ARGUMENTS:
  <folder-path>           Path to the folder containing .lungfishfastq bundles

OPTIONS:
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.


==== metadata export-biosample ====
OVERVIEW: Export folder metadata as NCBI BioSample submission TSV

Reads metadata from all .lungfishfastq bundles in a folder and outputs
an NCBI BioSample-compatible TSV file. This format can be submitted
directly to NCBI's BioSample submission portal.

Examples:
  lungfish metadata export-biosample ./RunFolder
  lungfish metadata export-biosample ./RunFolder > biosample.tsv
  lungfish metadata export-biosample ./RunFolder --package environmental

USAGE: lungfish-cli metadata export-biosample <folder-path> [--package <package>] [--format <format>] [--verbose ...] [--quiet] [--progress] [--no-progress] [--debug] [--log-file <log-file>] [--no-color] [--threads <threads>]

ARGUMENTS:
  <folder-path>           Path to the folder containing .lungfishfastq bundles

OPTIONS:
  --package <package>     BioSample package: clinical (default) or
                          environmental (default: clinical)
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.
