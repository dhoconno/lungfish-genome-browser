==== genotype ====
OVERVIEW: Inspect and annotate ONT genotype result bundles

Operate on `.lungfishgenotype` bundles produced by the genotype
pipelines. All subcommands take `--bundle <path>` and either print
to stdout (read-only inspection) or merge into the annotation
sidecar (`annotations.json`) that lives next to the bundle's
primary `genotype-result.json` manifest. The `ai-haplotyping`
subcommand is a scientific write workflow: it appends a versioned
AI haplotype analysis revision with provenance and review metadata.

USAGE: lungfish-cli genotype <subcommand>

OPTIONS:
  --version               Show the version.
  -h, --help              Show help information.

SUBCOMMANDS:
  list-samples            List samples and their top genotype call per locus
                          from a genotype bundle
  list-cohorts            List smart cohorts defined in a genotype bundle's
                          annotation sidecar
  ai-haplotyping          Run AI discovery or AI refinement haplotyping on a
                          genotype bundle.
  apply-annotations       Merge an annotation patch JSON into a genotype
                          bundle's annotation sidecar
  replay-matrix-annotation
                          Replay a recorded matrix annotation edit to an
                          explicit annotation sidecar
  replay-manual-haplotype-assignments
                          Replay a recorded manual haplotype assignment edit
                          into its exact target bundle
  replay-call-overrides   Replay a recorded atomic haplotype call override edit
                          into its exact target bundle
  export                  Export a genotype bundle (or a rendered view
                          projection) as XLSX/CSV/TSV.
  export-xlsx             Export the genotype bundle's matrix and analyst
                          annotations as an XLSX file.
  export-pivot-xlsx       Export the genotype bundle as a pivot-format XLSX
                          (samples across, alleles down).
  export-labkey           Export the genotype bundle's analyst-reviewed results
                          as LabKey-ready CSV files.

  See 'lungfish-cli help genotype <subcommand>' for detailed help.

==== genotype ai-haplotyping ====
OVERVIEW: Run AI discovery or AI refinement haplotyping on a genotype bundle.

USAGE: lungfish-cli genotype ai-haplotyping <options>

OPTIONS:
  --bundle <bundle>       Path to the `.lungfishgenotype` result bundle.
  --input-table <input-table>
                          Long-form CSV/TSV/JSON genotype rows for prompt
                          preview testing.
  --input-format <input-format>
                          Input table format: auto, csv, tsv, or json. (values:
                          auto, csv, tsv, json; default: auto)
  --preview-prompt        Render prompt/evidence JSON without contacting an AI
                          provider or publishing a revision.
  --output <output>       Optional output JSON path for prompt preview
                          artifacts.
  --debug-output <debug-output>
                          Write validated AI haplotyping debug JSON without
                          publishing a haplotype revision.
  --mode <mode>           AI haplotyping mode: ai-discovery or ai-refinement.
                          (values: ai-discovery, ai-refinement; default:
                          ai-refinement)
  --provider <provider>   AI provider: openai or anthropic. (values: openai,
                          anthropic; default: openai)
  --model <model>         Provider model override. Defaults to the provider's
                          app default.
  --azure-openai-endpoint <azure-openai-endpoint>
                          Azure OpenAI endpoint, such as
                          https://example.openai.azure.com.
  --azure-openai-deployment <azure-openai-deployment>
                          Azure OpenAI deployment name to use instead of a
                          direct OpenAI model.
  --prompt-template-id <prompt-template-id>
                          Prompt template ID to pin for this run.
  --prompt-template-version <prompt-template-version>
                          Prompt template version to pin for this run.
  --max-observations-per-chunk <max-observations-per-chunk>
                          Maximum observation evidence records per AI request.
                          Defaults high enough to keep each sample in one
                          review chunk. (default: 10000)
  --max-output-tokens <max-output-tokens>
                          Maximum provider output tokens per chunk. (default:
                          4096)
  --temperature <temperature>
                          Provider sampling temperature. (default: 0.0)
  --reasoning-effort <reasoning-effort>
                          OpenAI Responses API reasoning effort: none, minimal,
                          low, medium, high, or xhigh.
  --max-provider-retries <max-provider-retries>
                          Maximum retry attempts for transient AI provider
                          failures per chunk. (default: 2)
  --compact-knowledge-pack
                          Retrieve only prompt-relevant knowledge-pack records
                          before contacting the AI provider.
  --review-scope <review-scope>
                          AI refinement review scope: all or unresolved-only.
                          (values: all, unresolved-only; default: all)
  --chunk-start-index <chunk-start-index>
                          1-based first evidence chunk to run for debug-output
                          smoke runs. (default: 1)
  --chunk-end-index <chunk-end-index>
                          1-based last evidence chunk to run for debug-output
                          smoke runs; 0 means through the final chunk.
                          (default: 0)
  --population <population>
                          Population hint for input-table prompt previews, such
                          as mcm or indian-rhesus.
  --assay-resolution <assay-resolution>
                          Assay resolution hint for input-table prompt
                          previews, such as short-exon-amplicon or full-length.
  --haplotype-definition <haplotype-definition>
                          Haplotype definition/framework hint for input-table
                          prompt previews.
  --haplotype-assay <haplotype-assay>
                          Haplotype assay hint for input-table prompt previews.
  --version               Show the version.
  -h, --help              Show help information.

==== genotype export ====
OVERVIEW: Export a genotype bundle (or a rendered view projection) as
XLSX/CSV/TSV.

USAGE: lungfish-cli genotype export [<options>] --bundle <bundle> --output <output>

OPTIONS:
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  -b, --bundle <bundle>   Path to the .lungfishgenotype bundle.
  --export-format <export-format>
                          Export container format: xlsx, csv, tsv (default:
                          xlsx). (values: xlsx, csv, tsv; default: xlsx)
  -o, --output <output>   Output file path.
  --lens <lens>           Viewport lens to record in provenance (e.g.
                          haplotype, allele).
  --min-reads <min-reads> Drop calls below this unique-read count.
  --filter <filter>       Named filter applied to the view (recorded in
                          provenance).
  --sample <sample>       Restrict to this sample (repeatable).
  --active-haplotype-definition <active-haplotype-definition>
                          Active haplotype definition set ID to resolve calls
                          against.
  --view-projection <view-projection>
                          Path to a GenotypeViewProjection JSON describing the
                          rendered viewport.
  --annotations <annotations>
                          Annotation sidecar to include in annotation-bearing
                          exports; defaults to bundle annotations.json when
                          present.
  --force                 Overwrite an existing output file.
  --version               Show the version.
  -h, --help              Show help information.

==== genotype export-pivot-xlsx ====
OVERVIEW: Export the genotype bundle as a pivot-format XLSX (samples across,
alleles down).

USAGE: lungfish-cli genotype export-pivot-xlsx --bundle <bundle> --output <output> [--min-reads <min-reads>] [--min-percent <min-percent>] [--keep-empty-rows] [--percent-basis <percent-basis>] [--source-workbook <source-workbook>]

OPTIONS:
  -b, --bundle <bundle>   Path to the .lungfishgenotype bundle.
  -o, --output <output>   Output XLSX path.
  --min-reads <min-reads> Drop allele values supported by fewer than this many
                          reads. Mirrors the inspector's Min Reads control; 0
                          disables the filter. (default: 0)
  --min-percent <min-percent>
                          Drop allele values below this percent of the sample's
                          retained reads. Mirrors the inspector's Min Percent
                          control; 0 disables the filter. (default: 0.0)
  --keep-empty-rows       Keep allele rows that are empty after filtering
                          instead of removing them.
  --percent-basis <percent-basis>
                          Denominator for --min-percent: 'sample-retained' (the
                          sample's retained reads) or 'viewed-locus' (the
                          sample's reads at the allele's locus, as the
                          inspector's Viewed Locus basis). (values:
                          sample-retained, viewed-locus; default:
                          sample-retained)
  --source-workbook <source-workbook>
                          Workbook to copy and filter. Defaults to the bundle's
                          current.xlsx when one exists, else its primary
                          workbook. The export is that workbook with only the
                          pivot sheet changed; when the bundle has no workbook
                          a pivot-only workbook is written instead.
  --version               Show the version.
  -h, --help              Show help information.
