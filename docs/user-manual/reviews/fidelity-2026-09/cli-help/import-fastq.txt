==== import-fastq ====
OVERVIEW: Batch-import sequencing reads into a Lungfish project

USAGE: lungfish-cli import-fastq [<options>] [<input> ...] --project <project>

ARGUMENTS:
  <input>                 Directory containing sequencing reads, FASTQ paths,
                          or unmapped ONT BAM paths

OPTIONS:
  --samplesheet <samplesheet>
                          CSV sample sheet with sample,r1,r2 columns and
                          optional metadata columns
  -p, --project <project> Path to .lungfish project directory
  --recipe <recipe>       Processing recipe: vsp2, wgs, hifi, none (default:
                          none) (default: none)
  --quality-binning <quality-binning>
                          Quality binning: illumina4, eightLevel, none
                          (default: illumina4) (default: illumina4)
  --log-dir <log-dir>     Directory for per-sample log files
  --dry-run               List detected pairs without importing
  --platform <platform>   Sequencing platform: illumina, ont, pacbio, ultima
                          (default: auto-detect)
  --no-optimize-storage   Skip read reordering for storage optimization
  --clumping-tool <clumping-tool>
                          Storage optimization tool: auto, bbtools,
                          trim-galore, none (default: platform-specific)
  --compression <compression>
                          Compression level: fast, balanced, maximum (default:
                          balanced) (default: balanced)
  --force                 Reimport samples even if bundle already exists
  --recursive             Recursively scan directories for FASTQ files
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.
