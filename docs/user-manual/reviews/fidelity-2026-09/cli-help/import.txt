==== import ====
OVERVIEW: Import files into a Lungfish project

Import various bioinformatics file types into a Lungfish project
directory. Each subcommand handles format-specific validation,
file organization, and summary output.

USAGE: lungfish-cli import <subcommand>

OPTIONS:
  --version               Show the version.
  -h, --help              Show help information.

SUBCOMMANDS:
  bam                     Import a BAM or CRAM alignment file
  vcf                     Import a VCF variant file
  fasta                   Import a standalone reference sequence file as a
                          .lungfishref bundle
  msa                     Import a multiple sequence alignment as a
                          .lungfishmsa bundle
  tree                    Import a phylogenetic tree as a .lungfishtree bundle
  fastq                   Batch-import FASTQ files or unmapped ONT BAM into a
                          Lungfish project
  geneious                Import a Geneious export into native Lungfish project
                          collections
  application-export      Import an external application export into native
                          Lungfish project collections
  sample-metadata         Import sample metadata CSV/TSV into variant tracks in
                          a reference bundle
  kraken2                 Import Kraken2 classification results
  esviritu                Import EsViritu viral detection results
  taxtriage               Import TaxTriage classification results
  nao-mgs                 Import NAO-MGS metagenomic surveillance results
  nvd                     Import NVD BLAST results
  cz-id                   Import hosted CZ-ID classification results into a
                          project
  metadata                Import sample metadata CSV/TSV into a result bundle

  See 'lungfish-cli help import <subcommand>' for detailed help.

==== import bam ====
OVERVIEW: Import a BAM or CRAM alignment file

USAGE: lungfish-cli import bam <input-file> [--output-dir <output-dir>] [--name <name>] [--format <format>] [--verbose ...] [--quiet] [--progress] [--no-progress] [--debug] [--log-file <log-file>] [--no-color] [--threads <threads>]

ARGUMENTS:
  <input-file>            Path to the BAM or CRAM file

OPTIONS:
  -o, --output-dir <output-dir>
                          Output project directory (default: current directory)
  --name <name>           Display name for the alignment track (default:
                          filename)
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.

==== import fastq ====
OVERVIEW: Batch-import FASTQ files or unmapped ONT BAM into a Lungfish project

USAGE: lungfish-cli import fastq [<options>] [<input> ...] --project <project>

ARGUMENTS:
  <input>                 Directory containing sequencing reads, FASTQ paths,
                          or unmapped ONT BAM paths

OPTIONS:
  --samplesheet <samplesheet>
                          CSV sample sheet with sample,r1,r2 columns and
                          optional metadata columns
  -p, --project <project> Path to .lungfish project directory
  --recipe <recipe>       Processing recipe: vsp2, wgs, hifi, none (default:
                          none) (default: none)
  --quality-binning <quality-binning>
                          Quality binning: illumina4, eightLevel, none
                          (default: illumina4) (default: illumina4)
  --log-dir <log-dir>     Directory for per-sample log files
  --dry-run               List detected pairs without importing
  --platform <platform>   Sequencing platform: illumina, ont, pacbio, ultima
                          (default: auto-detect)
  --no-optimize-storage   Skip read reordering for storage optimization
  --clumping-tool <clumping-tool>
                          Storage optimization tool: auto, bbtools,
                          trim-galore, none (default: platform-specific)
  --compression <compression>
                          Compression level: fast, balanced, maximum (default:
                          balanced) (default: balanced)
  --force                 Reimport samples even if bundle already exists
  --recursive             Recursively scan directories for FASTQ files
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.
