==== analyze ====
OVERVIEW: Analyze sequences and generate statistics

USAGE: lungfish-cli analyze <subcommand>

OPTIONS:
  --version               Show the version.
  -h, --help              Show help information.

SUBCOMMANDS:
  stats (default)         Calculate sequence statistics
  composition             Calculate detailed nucleotide/amino acid composition
  validate                Validate sequence file format

  See 'lungfish-cli help analyze <subcommand>' for detailed help.

==== analyze stats ====
OVERVIEW: Calculate sequence statistics

Calculate statistics for sequence files including:
- Sequence count and total length
- GC content
- N50/N90 values
- Length distribution

Examples:
  lungfish analyze stats genome.fasta
  lungfish analyze stats reads.fastq --per-sequence

USAGE: lungfish-cli analyze stats [<options>] <input>

ARGUMENTS:
  <input>                 Input file path

OPTIONS:
  --per-sequence          Show statistics per sequence
  --gc/--no-gc            Calculate GC content (use --no-gc to skip) (default:
                          --gc)
  --length-distribution   Show length distribution
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.


==== analyze composition ====
OVERVIEW: Calculate detailed nucleotide/amino acid composition

Calculate detailed composition statistics including:
- Per-base/residue counts and percentages
- Purine/pyrimidine ratios (nucleotides)
- GC/AT skew (nucleotides)
- Codon usage table (nucleotides, --codons)
- Dinucleotide frequencies (nucleotides, --dinucleotides)

Positional counts reset at every record boundary. Codons use frame +1
of each record; incomplete terminal codons and windows containing
ambiguous symbols are excluded from frequency denominators.

Examples:
  lungfish analyze composition genome.fasta
  lungfish analyze composition coding.fasta --codons
  lungfish analyze composition genome.fasta --dinucleotides
  lungfish analyze composition protein.faa --alphabet protein

USAGE: lungfish-cli analyze composition [<options>] <input>

ARGUMENTS:
  <input>                 Input file path

OPTIONS:
  --codons                Show codon usage table (nucleotide sequences only)
  --dinucleotides         Show dinucleotide frequencies (nucleotide sequences
                          only)
  --alphabet <alphabet>   Sequence alphabet: dna, rna, protein (default:
                          auto-detect from file extension)
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.


==== analyze validate ====
OVERVIEW: Validate sequence file format

Validate that a file is well-formed and conforms to format specifications.

Examples:
  lungfish analyze validate genome.fasta
  lungfish analyze validate variants.vcf --strict

USAGE: lungfish-cli analyze validate <files> ... [--strict] [--format <format>] [--verbose ...] [--quiet] [--progress] [--no-progress] [--debug] [--log-file <log-file>] [--no-color] [--threads <threads>]

ARGUMENTS:
  <files>                 Input file(s) to validate

OPTIONS:
  --strict                Enable strict validation
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.
