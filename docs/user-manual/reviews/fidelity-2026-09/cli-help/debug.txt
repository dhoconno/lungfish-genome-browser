==== debug ====
OVERVIEW: Debugging and troubleshooting tools

USAGE: lungfish-cli debug <subcommand>

OPTIONS:
  --version               Show the version.
  -h, --help              Show help information.

SUBCOMMANDS:
  env (default)           Check environment and dependencies
  container               Apple Container runtime diagnostics
  resource-smoke          Verify packaged runtime resources without launching
                          the app UI
  fastq-ingest            Run FASTQ clumpify/compress/index + optional stats
  workflow-log            Parse and analyze workflow logs

  See 'lungfish-cli help debug <subcommand>' for detailed help.

==== debug env ====
OVERVIEW: Check environment and dependencies

Verify that all required tools and dependencies are available.

Examples:
  lungfish debug env
  lungfish debug env --check-tools

USAGE: lungfish-cli debug env [--check-tools] [--tool <tool>] [--format <format>] [--verbose ...] [--quiet] [--progress] [--no-progress] [--debug] [--log-file <log-file>] [--no-color] [--threads <threads>]

OPTIONS:
  --check-tools           Check bioinformatics tools availability
  --tool <tool>           Check specific tool
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.

==== debug fastq-ingest ====
OVERVIEW: Run FASTQ clumpify/compress/index + optional stats

Executes the same FASTQ ingestion pipeline used by app imports.

Examples:
  lungfish debug fastq-ingest ./SRR1770413_1.fastq.gz --stats --sample-limit 0
  lungfish debug fastq-ingest ./R1.fastq.gz --pair ./R2.fastq.gz
--delete-originals

USAGE: lungfish-cli debug fastq-ingest [<options>] <input>

ARGUMENTS:
  <input>                 Input FASTQ file (R1 for paired-end)

OPTIONS:
  --pair <pair>           Optional R2 FASTQ file for paired-end mode
  --output-dir <output-dir>
                          Output directory for processed FASTQ (default: .)
  --binning <binning>     Quality binning scheme (illumina4, eightLevel, none)
                          (default: illumina4)
  --skip-clumpify         Skip read clumpification step
  --delete-originals      Delete original FASTQ file(s) after success
  --stats                 Compute FASTQ statistics on processed output
  --sample-limit <sample-limit>
                          Read sample limit for stats (0 = full dataset)
                          (default: 10000)
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.


==== debug workflow-log ====
OVERVIEW: Parse and analyze workflow logs

Parse Nextflow or Snakemake execution logs for debugging.

Examples:
  lungfish debug workflow-log ./work
  lungfish debug workflow-log ./work --errors-only
  lungfish debug workflow-log .nextflow.log --timeline

USAGE: lungfish-cli debug workflow-log [<options>] <path>

ARGUMENTS:
  <path>                  Log file or work directory

OPTIONS:
  --errors-only           Show only error messages
  --timeline              Show execution timeline
  --process <process>     Filter by process name
  --resource-usage        Show resource usage statistics
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.
