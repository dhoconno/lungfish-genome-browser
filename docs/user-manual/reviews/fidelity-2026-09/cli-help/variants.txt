==== variants ====
OVERVIEW: Call viral variants from a bundle-owned alignment track

USAGE: lungfish-cli variants <subcommand>

OPTIONS:
  --version               Show the version.
  -h, --help              Show help information.

SUBCOMMANDS:
  call                    Call viral variants from a bundle-owned alignment
                          track
  phase                   Construct a phase-aware GATK HaplotypeCaller plus
                          WhatsHap command plan
  extract-sample          Extract one sample's variant calls from a bundle
                          variant database
  query                   Query bundle variants with a per-sample smart filter

  See 'lungfish-cli help variants <subcommand>' for detailed help.

==== variants call ====
OVERVIEW: Call viral variants from a bundle-owned alignment track

USAGE: lungfish-cli variants call [<options>] --bundle <bundle> --alignment-track <alignment-track> --caller <caller>

OPTIONS:
  --bundle <bundle>       Path to the reference bundle directory
  --alignment-track <alignment-track>
                          Bundle alignment track identifier
  --caller <caller>       Variant caller: lofreq, ivar, medaka, bcftools, clair3
  --name, --output-track-name <name>
                          Display name for the created variant track
  --min-af <min-af>       Minimum allele frequency threshold
  --min-depth <min-depth> Minimum depth threshold
  --ivar-primer-trimmed   Confirm the BAM was primer-trimmed before iVar calling
  --medaka-model <medaka-model>
                          Required ONT/basecaller model identifier or Clair3
                          model path
  --ivar-consensus-af <ivar-consensus-af>
                          Allele frequency threshold above which an iVar
                          haplotype counts as consensus (default 0.75)
                          (default: 0.75)
  --ivar-merge-af-threshold <ivar-merge-af-threshold>
                          Maximum allele frequency distance for merging
                          adjacent iVar SNPs (default 0.25) (default: 0.25)
  --ivar-bad-quality-threshold <ivar-bad-quality-threshold>
                          iVar ALT_QUAL below this fails the bq filter (default
                          20) (default: 20)
  --ivar-no-ignore-strand-bias
                          Apply iVar strand-bias filter (off by default for
                          amplicon data)
  --extra-args, --advanced-options <extra-args>
                          Additional caller arguments, written exactly as they
                          should be passed to the underlying tool
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.


==== variants phase ====
OVERVIEW: Construct a phase-aware GATK HaplotypeCaller plus WhatsHap command
plan

USAGE: lungfish-cli variants phase [--execute] [--dry-run] --reference <reference> --bam <bam> --output-vcf <output-vcf> [--output-dir <output-dir>] [--sample <sample>] [--threads <threads>] [--extra-gatk-args <extra-gatk-args>] [--extra-whatshap-args <extra-whatshap-args>]

OPTIONS:
  --execute               Run GATK and WhatsHap through managed tool packs.
  --dry-run               Write and print the command plan without running
                          tools.
  --reference <reference> Reference FASTA path
  --bam <bam>             Input BAM path
  --output-vcf <output-vcf>
                          Final phased VCF path
  --output-dir <output-dir>
                          Command-plan/provenance output directory
  --sample <sample>       Optional sample name passed to WhatsHap
  --threads <threads>     GATK PairHMM threads (default: 1)
  --extra-gatk-args <extra-gatk-args>
                          Additional GATK HaplotypeCaller arguments
  --extra-whatshap-args <extra-whatshap-args>
                          Additional WhatsHap phase arguments
  --version               Show the version.
  -h, --help              Show help information.

==== variants query ====
OVERVIEW: Query bundle variants with a per-sample smart filter

USAGE: lungfish-cli variants query [<options>] <bundle-path> --filter <filter> --output <output>

ARGUMENTS:
  <bundle-path>           Path to a .lungfishref bundle with a variant database

OPTIONS:
  --filter <filter>       Smart filter, e.g. Sample[NA12878].GT=1/1
  -o, --output <output>   Output VCF path
  --limit <limit>         Maximum variants to export (default: 5000)
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.
