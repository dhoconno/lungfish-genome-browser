==== msa ====
OVERVIEW: Inspect and run multiple sequence alignment actions

USAGE: lungfish-cli msa <subcommand>

OPTIONS:
  --version               Show the version.
  -h, --help              Show help information.

SUBCOMMANDS:
  actions                 List registered multiple sequence alignment actions
  describe                Describe one registered multiple sequence alignment
                          action
  annotate                Create and manage multiple sequence alignment
                          annotations
  export                  Export a .lungfishmsa alignment with provenance
  consensus               Create a consensus sequence from a .lungfishmsa bundle
  extract                 Extract selected rows and columns from a .lungfishmsa
                          bundle
  mask                    Create derived MSA bundles with non-destructive masks
  trim                    Create derived MSA bundles with removed columns
  distance                Compute identity or p-distance matrices from a
                          .lungfishmsa bundle

  See 'lungfish-cli help msa <subcommand>' for detailed help.

==== msa actions ====
OVERVIEW: List registered multiple sequence alignment actions

USAGE: lungfish-cli msa actions [--category <category>] [--cli-backed] [--data-changing] [--format <format>] [--verbose ...] [--quiet] [--progress] [--no-progress] [--debug] [--log-file <log-file>] [--no-color] [--threads <threads>]

OPTIONS:
  --category <category>   Optional category filter
  --cli-backed            Only show actions with a CLI contract
  --data-changing         Only show actions that create or modify scientific
                          data
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.

==== msa mask columns ====
OVERVIEW: Create a derived .lungfishmsa bundle with masked alignment columns

USAGE: lungfish-cli msa mask columns [<options>] <bundle-path> --output <output>

ARGUMENTS:
  <bundle-path>           Input .lungfishmsa bundle

OPTIONS:
  --ranges <ranges>       1-based aligned column ranges to mask, e.g. 10-40,55
  --gap-threshold <gap-threshold>
                          Mask columns with gap fraction greater than or equal
                          to this value
  --conservation-below <conservation-below>
                          Mask columns whose non-gap majority residue fraction
                          is below this value
  --parsimony-uninformative
                          Mask columns that are not parsimony-informative
  --annotation <annotation>
                          Mask columns spanned by an MSA annotation ID or
                          source annotation ID
  --codon-position <codon-position>
                          Mask columns corresponding to CDS codon position 1,
                          2, or 3
  --output <output>       Output .lungfishmsa bundle path
  --name <name>           Output bundle name
  --reason <reason>       Optional mask reason
  --force                 Overwrite an existing output bundle
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.
