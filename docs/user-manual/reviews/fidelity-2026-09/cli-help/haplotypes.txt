==== haplotypes ====
OVERVIEW: Manage ONT genotyping haplotype definition sets

Import, export, list, duplicate, and delete project haplotype definition
sets before running ONT genotyping workflows. Definitions may be stored
as project JSON definition files or embedded in project .lungfishmhcref
reference bundles.

USAGE: lungfish-cli haplotypes <subcommand>

OPTIONS:
  --version               Show the version.
  -h, --help              Show help information.

SUBCOMMANDS:
  list                    List haplotype definition sets
  validate                Validate a haplotype definition JSON file
  import                  Import a haplotype definition JSON file
  save                    Save or update a writable haplotype definition from a
                          JSON file
  bundle-install          Install an existing .lungfishmhcref bundle into a
                          project
  bundle-create           Create an MHC reference bundle from managed haplotype
                          definitions and a reference FASTA
  bundle-save             Save or update a haplotype definition embedded in an
                          MHC reference bundle
  bundle-replace-reference
                          Replace the reference FASTA embedded in an MHC
                          reference bundle
  export                  Export a haplotype definition set to a JSON file
  duplicate               Duplicate a project definition into the project scope
  delete                  Delete a project haplotype definition set

  See 'lungfish-cli help haplotypes <subcommand>' for detailed help.

==== haplotypes list ====
OVERVIEW: List haplotype definition sets

USAGE: lungfish-cli haplotypes list [--project <project>] [--assay <assay>] [--species <species>] [--scope <scope>] [--include-shadowed] [--include-reference-bundles]

OPTIONS:
  --project <project>     Project root whose project-scoped definitions should
                          be included
  --assay <assay>         Filter to an assay/amplicon id
  --species <species>     Filter to a species code, such as MCM or MAMU
  --scope <scope>         project (the only supported scope)
  --include-shadowed      Include definitions overridden by a higher-precedence
                          scope
  --include-reference-bundles
                          Include haplotype definitions embedded in project
                          .lungfishmhcref bundles
  --version               Show the version.
  -h, --help              Show help information.

==== haplotypes bundle-create ====
OVERVIEW: Create an MHC reference bundle from managed haplotype definitions and
a reference FASTA

USAGE: lungfish-cli haplotypes bundle-create [--definition <definition> ...] [--assay <assay>] [--species <species>] [--scope <scope>] --reference-fasta <reference-fasta> --output <output> [--name <name>] [--default-definition <default-definition>] [--project <project>] [--force]

OPTIONS:
  --definition <definition>
                          Managed haplotype definition id to embed
  --assay <assay>         Assay/amplicon id used to disambiguate definition ids
  --species <species>     Species code used to disambiguate definition ids
  --scope <scope>         project (the only supported scope)
  --reference-fasta <reference-fasta>
                          MHC amplicon reference FASTA to embed
  --output <output>       Output .lungfishmhcref bundle
  --name <name>           Display name stored in the bundle manifest
  --default-definition <default-definition>
                          Default embedded haplotype definition set ID
  --project <project>     Project root whose project-scoped definitions should
                          be included
  --force                 Replace an existing .lungfishmhcref bundle
  --version               Show the version.
  -h, --help              Show help information.

==== haplotypes duplicate ====
OVERVIEW: Duplicate a project definition into the project scope

USAGE: lungfish-cli haplotypes duplicate <definition-id> [--project <project>] [--assay <assay>] [--source-scope <source-scope>] [--target-scope <target-scope>] [--new-definition-id <new-definition-id>] [--change-note <change-note>]

ARGUMENTS:
  <definition-id>         Definition set id to duplicate

OPTIONS:
  --project <project>     Project root for project-scoped definitions
  --assay <assay>         Assay/amplicon id used to disambiguate duplicate
                          definition ids
  --source-scope <source-scope>
                          project (the only supported scope)
  --target-scope <target-scope>
                          project (the only supported scope) (default: project)
  --new-definition-id <new-definition-id>
                          Optional id for the duplicate; omit to
                          override/shadow the source id
  --change-note <change-note>
                          Human-readable provenance note for this duplication
  --version               Show the version.
  -h, --help              Show help information.
