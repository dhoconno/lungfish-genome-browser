==== project ====
OVERVIEW: Manage shared project locks and bundle migrations

Project commands provide explicit coordination primitives for shared
Lungfish project directories. Lock records are stored inside the
project so GUI and CLI tooling can detect active advanced workflows.

USAGE: lungfish-cli project <subcommand>

OPTIONS:
  --version               Show the version.
  -h, --help              Show help information.

SUBCOMMANDS:
  lock                    Create a project-local lock record
  unlock                  Remove a project-local lock record
  migrate                 Migrate project bundles when a safe transformer is
                          available

  See 'lungfish-cli help project <subcommand>' for detailed help.

==== project lock ====
OVERVIEW: Create a project-local lock record

USAGE: lungfish-cli project lock <project-path> [--mode <mode>] [--force] [--format <format>] [--verbose ...] [--quiet] [--progress] [--no-progress] [--debug] [--log-file <log-file>] [--no-color] [--threads <threads>]

ARGUMENTS:
  <project-path>          Path to the Lungfish project directory

OPTIONS:
  --mode <mode>           Lock mode to record for tools and GUI clients
                          (default: exclusive)
  --force                 Replace an active lock without stale-owner checks
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.

==== project migrate ====
OVERVIEW: Migrate project bundles when a safe transformer is available

The migration command is intentionally conservative. It scans
Lungfish bundles inside a project, leaves current-version bundles
untouched, and reports unsupported legacy schemas without
mutating data until a schema-specific transformer exists.

USAGE: lungfish-cli project migrate <project-path> [--dry-run] [--format <format>] [--verbose ...] [--quiet] [--progress] [--no-progress] [--debug] [--log-file <log-file>] [--no-color] [--threads <threads>]

ARGUMENTS:
  <project-path>          Path to the Lungfish project directory

OPTIONS:
  --dry-run               Report planned actions without modifying files
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.
