==== bundle ====
OVERVIEW: Manage reference genome bundles (.lungfishref)

Reference genome bundles are directory packages containing a genome sequence,
annotations, variants, and signal tracks in optimized binary formats.

Use these commands to create, inspect, and validate bundles.

Examples:
  lungfish bundle info MyGenome.lungfishref
  lungfish bundle create --fasta genome.fa --name "My Genome" --output ./
  lungfish bundle validate MyGenome.lungfishref

USAGE: lungfish-cli bundle <subcommand>

OPTIONS:
  --version               Show the version.
  -h, --help              Show help information.

SUBCOMMANDS:
  info (default)          Display bundle information
  create                  Create a new reference bundle
  extract-annotations     Extract annotation feature sequences into a new
                          .lungfishref bundle
  deduplicate-alignments  Create a bundle with duplicate reads removed from
                          alignment tracks
  export                  Export a bundle to a portable artifact
  validate                Validate a reference bundle
  list                    List bundle contents

  See 'lungfish-cli help bundle <subcommand>' for detailed help.

==== bundle info ====
OVERVIEW: Display bundle information

Shows detailed information about a reference bundle including:
- Name, identifier, and description
- Source organism and assembly
- Genome size and chromosome count
- Annotation, variant, and signal tracks

Examples:
  lungfish bundle info MyGenome.lungfishref
  lungfish bundle info MyGenome.lungfishref --format json

USAGE: lungfish-cli bundle info <bundle-path> [--format <format>] [--verbose ...] [--quiet] [--progress] [--no-progress] [--debug] [--log-file <log-file>] [--no-color] [--threads <threads>]

ARGUMENTS:
  <bundle-path>           Path to the .lungfishref bundle

OPTIONS:
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.


==== bundle create ====
OVERVIEW: Create a new reference bundle

Creates a new .lungfishref bundle from source files.

Required: FASTA sequence file
Optional: Annotation files (GFF3, GTF, BED), variant files (VCF)

Examples:
  lungfish bundle create --fasta genome.fa --name "My Genome" --output-dir
./bundles
  lungfish bundle create --fasta genome.fa --annotation genes.gff3 --name
"Annotated Genome" --output-dir ./

USAGE: lungfish-cli bundle create [<options>] --fasta <fasta> --name <name> --output-dir <output-dir>

OPTIONS:
  --fasta <fasta>         Input FASTA file (required)
  --name <name>           Bundle name (required)
  --output-dir <output-dir>
                          Output directory (required)
  --identifier <identifier>
                          Bundle identifier (default: auto-generated)
  --bundle-description <bundle-description>
                          Bundle description
  --organism <organism>   Source organism name (default: Unknown)
  --assembly <assembly>   Assembly name (default: Unknown)
  --annotation <annotation>
                          Annotation file(s) to include
  --variant <variant>     Variant file(s) to include
  --compress              Compress FASTA with bgzip
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.

==== bundle deduplicate-alignments ====
OVERVIEW: Create a bundle with duplicate reads removed from alignment tracks

Copies a .lungfishref bundle, runs the shared duplicate-removal workflow on
every alignment track, and records reproducibility provenance in the output
bundle.

Examples:
  lungfish bundle deduplicate-alignments MyGenome.lungfishref
  lungfish bundle deduplicate-alignments MyGenome.lungfishref --output
MyGenome-dedup.lungfishref

USAGE: lungfish-cli bundle deduplicate-alignments <bundle-path> [--output <output>] [--format <format>] [--verbose ...] [--quiet] [--progress] [--no-progress] [--debug] [--log-file <log-file>] [--no-color] [--threads <threads>]

ARGUMENTS:
  <bundle-path>           Path to the source .lungfishref bundle

OPTIONS:
  -o, --output <output>   Output .lungfishref bundle path
  --format <format>       Output format: text, json (default: text) (values:
                          text, json; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)

  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.


==== bundle export ====
OVERVIEW: Export a bundle to a portable artifact

Exports a Lungfish bundle as a deterministic OCI layout tarball.

Examples:
  lungfish bundle export MyGenome.lungfishref --format container --output
MyGenome.oci.tar

USAGE: lungfish-cli bundle export <bundle-path> --format <format> --output <output> [--plugin-pack <plugin-pack> ...] [--quiet]

ARGUMENTS:
  <bundle-path>           Path to the source .lungfishref bundle

OPTIONS:
  --format <format>       Export format
  -o, --output <output>   Output tarball path
  --plugin-pack <plugin-pack>
                          Plugin pack ID to pin into the exported image metadata
  -q, --quiet             Suppress non-essential output
  --version               Show the version.
  -h, --help              Show help information.


==== bundle validate ====
OVERVIEW: Validate a reference bundle

Validates the structure and integrity of a .lungfishref bundle.

Checks:
- manifest.json exists and is valid
- All referenced files exist
- Genome sequence is readable
- Index files are valid

Examples:
  lungfish bundle validate MyGenome.lungfishref
  lungfish bundle validate *.lungfishref

USAGE: lungfish-cli bundle validate <bundles> ... [--check-integrity] [--format <format>] [--verbose ...] [--quiet] [--progress] [--no-progress] [--debug] [--log-file <log-file>] [--no-color] [--threads <threads>]

ARGUMENTS:
  <bundles>               Bundle path(s) to validate

OPTIONS:
  --check-integrity       Check file integrity (slower)
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.
