==== provenance ====
OVERVIEW: Inspect provenance recorded in Lungfish bundles

USAGE: lungfish-cli provenance <subcommand>

OPTIONS:
  --version               Show the version.
  -h, --help              Show help information.

SUBCOMMANDS:
  bibliography            Generate a citation list from a bundle's provenance
  export                  Export reproducible reports from a Lungfish
                          provenance sidecar
  verify                  Verify a signed Lungfish provenance sidecar

  See 'lungfish-cli help provenance <subcommand>' for detailed help.

==== provenance bibliography ====
OVERVIEW: Generate a citation list from a bundle's provenance

USAGE: lungfish-cli provenance bibliography <bundle>

ARGUMENTS:
  <bundle>                Bundle or output directory containing Lungfish
                          provenance

OPTIONS:
  --version               Show the version.
  -h, --help              Show help information.


==== provenance export ====
OVERVIEW: Export reproducible reports from a Lungfish provenance sidecar

USAGE: lungfish-cli provenance export <input> --format <format> --output <output>

ARGUMENTS:
  <input>                 Provenance sidecar file, bundle, or output directory

OPTIONS:
  -f, --format, --export-format <format>
                          Export format: shell, python, nextflow, snakemake,
                          methods, json
  --output <output>       Output directory for the export bundle
  --version               Show the version.
  -h, --help              Show help information.


==== provenance verify ====
OVERVIEW: Verify a signed Lungfish provenance sidecar

USAGE: lungfish-cli provenance verify <file> [--signature <signature>] [--public-key <public-key>]

ARGUMENTS:
  <file>                  Provenance sidecar file, bundle, or output directory

OPTIONS:
  --signature <signature> Signature artifact path; defaults to
                          <sidecar>.signature.json
  --public-key <public-key>
                          Public key artifact path; defaults to <sidecar>.pub
  --version               Show the version.
  -h, --help              Show help information.
