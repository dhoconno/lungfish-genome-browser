## Campaign-wide finding that affects all eight chapters

Every chapter in this part routes the reader through a menu path of the shape `Tools > FASTQ/FASTA Operations > <Category>…`. No such submenu exists. `MainMenu.swift:702-704` builds the Tools menu by adding one submenu per `FASTQOperationCategoryID` directly at the top level of Tools, using `ToolsMenuModel.build`. `MainMenu.swift:804-817` fills each category submenu with one item per operation, titled with the operation name plus an ellipsis. The correct shape is therefore `Tools > <Category> > <Operation>…`, for example `Tools > Trimming & Filtering > Quality Trim…`. Category titles come from `ToolsMenuModel.swift:63-75`. The dialog that opens is titled "FASTQ/FASTA Operations" (`FASTQOperationDialogState.swift:1250-1252`), which is presumably where the wrong menu path came from. Each chapter's rows below repeat this verdict against its own quoted wording so the rewrite has the exact strings.
