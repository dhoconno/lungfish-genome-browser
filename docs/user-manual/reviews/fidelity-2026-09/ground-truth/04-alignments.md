Campaign-wide finding that touches every chapter in this part. The Tools menu no
longer has a "FASTQ/FASTA Operations" item. `MainMenu.swift:703-706` builds one
top-level Tools submenu per `FASTQOperationCategoryID`, titled by
`ToolsMenuModel.swift:60-75`, so the Mapping category is reached at
`Tools > Mapping`. `MainMenu.swift:804-817` fills that submenu with one item per
tool id from `FASTQOperationDialogState.toolIDs(for:)`, each titled with a
trailing ellipsis. `FASTQOperationDialogState.swift:1279` returns
`[.minimap2, .bwaMem2, .bowtie2, .bbmap, .viralRecon]` for `.mapping`, so the
five items are minimap2…, BWA-MEM2…, Bowtie2…, BBMap…, Viral Recon….
The corrected path everywhere in this part is `Tools > Mapping > <tool>…`,
selecting the tool directly rather than opening a dialog and clicking a row.

Second campaign-wide finding. The Inspector's Analysis section is not a flat
list of buttons. `ReadStyleSection.swift:2047` renders an
`AnalysisSubsectionGrid` of the six `AnalysisWorkflowSubsection` cases
(`ReadStyleSection.swift:1025-1051`) titled Filtering, Annotations, Consensus,
Primer Trim, Variant Calling, Export, and `ReadStyleSection.swift:2050-2062`
shows one subsection at a time. Every "Inspector > Analysis > <button>"
instruction in this part needs the subsection tab named before the button.
