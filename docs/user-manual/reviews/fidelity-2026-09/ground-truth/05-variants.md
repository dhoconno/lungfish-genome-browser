Standing note that governs many rows below. There is no dedicated variant browser
viewport reached by clicking a variant track in the sidebar. Variant rows live in
the shared bottom table drawer (`AnnotationTableDrawerView`) attached to the
reference bundle viewport, on its Variants tab. The drawer opens by itself when
the loaded bundle manifest carries at least one annotation or variant track
(`Sources/LungfishApp/Views/Viewer/ViewerViewController+AnnotationDrawer.swift:90-107`).
The sidebar has no per-variant-track node
(`Sources/LungfishApp/Views/Sidebar/SidebarItem.swift:230` maps variants onto the
annotation kind, and the only variant sidebar affordance is the context-menu item
`Delete Variant Tracks…` at
`Sources/LungfishApp/Views/Sidebar/SidebarViewController+MenuDelegate.swift:202`).
`VCFDatasetViewController.swift` is a separate standalone VCF dataset viewer with
its own smaller column set and no Source column.

Second standing note. The variant free-text filter field is permanently hidden
(`AnnotationTableDrawerView+Columns.swift:92`, comment `Always hidden; Query
Builder writes to variantFilterText directly`). Filtering is driven by the
`Presets ▸` chip strip and the `Search Builder...` sheet. Every chapter passage
that tells the reader to type into a free-text filter field, or to clear it with
an `x`, is describing a control the user cannot reach.
