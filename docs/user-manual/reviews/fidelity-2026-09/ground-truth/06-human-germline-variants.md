Campaign-level notes that apply to all four chapters:

1. The June 2026 finding that the chapters described GATK as "coming soon" while it already ran has been fixed. All four current chapters describe `--execute` as real. That whole class of June defect is resolved, so no row below repeats it.
2. The single largest new defect in this part is the `conda install --pack` instruction in chapter 04. Both `gatk-core` and `phasing` are experimental packs, and the CLI installer resolves pack ids only against `PluginPack.visibleForCLI`, which excludes experimental packs. The two documented install commands therefore fail.
3. The second largest new defect is chapter 01's description of the **GATK + WhatsHap Phased** GUI tool. Selecting it and clicking Run produces no run at all. The dialog state sets both `pendingGATKRequest` and `pendingRequest` to nil for that tool, and nothing in `LungfishApp` ever reads `pendingPhasedVariantPlan`, so the Inspector falls through to a "Variant Calling Not Ready" alert.
4. The manual nav labels this part "Human Germline Variants (Preview)" in `docs/user-manual/build/mkdocs.yml:116`, which matches. Two of the four nav item labels do not match their chapter titles (rows recorded per chapter).
