## Full-length ONT MHC genotyping

Reference matching is now completeness-aware. A genomic allele that already spans exon 1 through its locus-specific terminal exon is treated as complete, so primer- or barcode-derived terminal sequence no longer causes an otherwise exact match to be mislabeled as a partial extension. Incomplete genomic references and cDNA references can still be extended to the full amplicon span.

Completeness is inferred from reference annotations using locus-aware exon expectations: class I and Mamu-E references accept terminal exon 7 or 8, while class II loci use their shorter locus-specific terminal exon. The inferred status and evidence are retained in genotyping provenance.

Generic `.lungfishref` bundles can also resolve curated allele and locus names from sequence annotations when record-store metadata and FASTA descriptions are unavailable. Curated `_ext` and `_nov` allele labels remain strict so malformed names still fail validation instead of being silently reinterpreted.
